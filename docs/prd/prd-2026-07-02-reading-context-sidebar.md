# LumenPDF — 阅读上下文右栏 PRD

**版本**: v1.0.12 · **日期**: 2026-07-02

---

## 1. 背景

LumenPDF 已经具备单词本、笔记、PDF 高亮 / 下划线恢复、来源页跳转等能力，但当前信息结构仍然以顶部 Tab 分离：用户阅读 PDF 时，若想回看当前文档中沉淀过的单词或笔记，需要切换到「单词本」或「笔记」页面，阅读上下文被打断。

本迭代希望把「知识沉淀」从独立管理页前移到阅读现场：在 PDF 阅读页右侧新增上下文栏，集中展示当前 PDF 的单词与笔记，并支持像在线文档评论一样快速定位回原文位置。

---

## 2. 目标

### 2.1 产品目标

1. **降低割裂感**：阅读 PDF 时即可看到当前文档相关的单词和笔记，不必离开阅读页。
2. **强化位置感**：单词 / 笔记卡片显示页码，点击后定位到 PDF 中对应位置。
3. **提升复习效率**：支持「全部 / 本页 / 单词 / 笔记」过滤，快速聚焦当前阅读页面的知识点。
4. **保留全局管理能力**：原「单词本」「笔记」Tab 继续用于全库搜索、编辑、导出与批量管理。

### 2.2 非目标

本迭代不做以下事项：

- 不移除顶部「单词本」「笔记」Tab。
- 不引入云同步或多用户协作。
- 不重构 Rust 存储模型。
- 不实现 PDF 标注点击反向定位右栏卡片。
- 不新增数据库迁移；MVP 复用现有 `page_index` 与 bounds 字段。

## 4. 功能需求

### F1 — 阅读页右侧上下文栏

- 在 PDF 阅读 Tab 中，当存在当前文档时，PDF 阅读区右侧展示上下文栏。
- 右栏默认开启，可通过工具栏按钮显示 / 隐藏。
- 右栏宽度固定在适合阅读的窄栏范围内，避免过度挤压 PDF。
- 未打开 PDF 时不展示右栏。

### F2 — 当前 PDF 数据过滤

右栏只展示当前 PDF 的数据：

- 单词：`VocabularyEntry.pdfPath == selectedDocument.filePath`
- 笔记：`NoteEntry.pdfPath == selectedDocument.filePath`

排序规则：

1. 页码升序；
2. 同页内按创建时间降序或稳定顺序展示；
3. 单词和笔记混排时，以页码为主。

### F3 — 快速筛选

右栏提供筛选入口：

- 内容类型：`全部 / 单词 / 笔记`
- 页面范围：`全部 / 本页`

筛选结果为空时展示空状态：

- 当前 PDF 无数据：提示「这个 PDF 还没有单词或笔记」。
- 当前页无数据：提示「当前页暂无单词或笔记」。

### F4 — 卡片展示

#### 单词卡片

显示：

- 单词；
- 语境翻译；
- 原文语境，最多展示若干行；
- 页码，如 `P198`；
- 类型标识「单词」。

#### 笔记卡片

显示：

- 划线原文；
- 用户笔记内容；
- 页码，如 `P198`；
- 类型标识「笔记」。

### F5 — 定位行为

点击右栏卡片后：

1. 确保仍处于 PDF 阅读 Tab；
2. 向 PDFReader 发送定位通知；
3. PDFReader 跳转到对应页面；
4. 如果条目包含 bounds，则尝试滚动到选区附近；
5. 以 Toast 告知已定位页码。

### F6 — 数据刷新

右栏应响应以下变化：

- 打开 / 切换当前 PDF；
- 保存单词；
- 删除单词；
- 新增笔记；
- 删除 / 编辑笔记；
- 当前页变化。

## 6. 成功指标

- 阅读页中查看当前 PDF 单词 / 笔记无需切换 Tab。
- 点击右栏条目跳转成功率接近 100%。
- 右栏筛选响应无明显卡顿。
- 用户可一键隐藏右栏，避免影响纯阅读。

## 7. 后续迭代
