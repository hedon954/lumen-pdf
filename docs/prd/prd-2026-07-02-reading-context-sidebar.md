# LumenPDF — 阅读上下文右栏 PRD

**版本**: v1.0.12 · **日期**: 2026-07-02

---

## 1. 背景

LumenPDF 已经具备单词本、笔记、PDF 高亮 / 下划线恢复、来源页跳转等能力，但当前信息结构仍然以顶部 Tab 分离：用户阅读 PDF 时，若想回看当前文档中沉淀过的单词或笔记，需要切换到「单词本」或「笔记」页面，阅读上下文被打断。

本迭代希望把「知识沉淀」从独立管理页前移到阅读现场：在 PDF 阅读页右侧新增上下文栏，集中展示当前 PDF 的单词与笔记，并支持像在线文档评论一样快速定位回原文位置。

---

## 2. 目标

### 2.1 产品目标

1. **降低割裂感**：阅读 PDF 时即可看到当前文档相关的单词和笔记，不必离开阅读页。
2. **强化位置感**：单词 / 笔记卡片显示页码，点击后定位到 PDF 中对应位置。
3. **提升复习效率**：在右栏顶部直接切换「单词 / 笔记」，列表默认跟随阅读位置滚动。
4. **保留全局管理能力**：原「单词本」「笔记」Tab 继续用于全库搜索、编辑、导出与批量管理。

### 2.2 非目标

本迭代不做以下事项：

- 不移除顶部「单词本」「笔记」Tab。
- 不引入云同步或多用户协作。
- 不重构 Rust 存储模型。
- 不实现 PDF 标注点击反向定位右栏卡片。
- 不新增数据库迁移；MVP 复用现有 `page_index` 与 bounds 字段。

## 4. 功能需求

### F1 — 阅读页右侧上下文栏

- 在 PDF 阅读 Tab 中，当存在当前文档时，PDF 阅读区右侧展示上下文栏。
- 右栏默认开启，可通过工具栏按钮显示 / 隐藏。
- 右栏宽度固定在适合阅读的窄栏范围内，避免过度挤压 PDF。
- 未打开 PDF 时不展示右栏。

### F2 — 当前 PDF 数据过滤

右栏只展示当前 PDF 的数据：

- 单词：`VocabularyEntry.pdfPath == selectedDocument.filePath`
- 笔记：`NoteEntry.pdfPath == selectedDocument.filePath`

排序规则：

1. 页码升序；
2. 同页内按创建时间降序或稳定顺序展示；
3. 单词和笔记混排时，以页码为主。

### F3 — 顶部类型切换与阅读位置跟随

右栏顶部只提供两个一级类型入口：`单词 / 笔记`。

- 不提供「全部」混合视图，避免单词和笔记在同一列表中互相打断。
- 不提供「全部范围 / 本页」范围筛选；列表默认展示当前 PDF 的全部同类条目。
- 阅读位置变化时，右栏自动滚动到当前页或当前页之后最近的条目。
- 用户手动滚动右栏到其他页码分组时，PDF 阅读区同步跳转到该页。
- 打开或关闭右栏导致 PDF 阅读区宽度变化时，应恢复到切换前的页码和页内滚动位置，避免回滚到前页。

### F4 — 卡片展示

#### 单词卡片

显示：

- 单词；
- 语境翻译；
- 原文语境，最多展示若干行；
- 页码，如 `P198`；
- 类型标识「单词」。

#### 笔记卡片

显示：

- 划线原文；
- 用户笔记内容；
- 页码，如 `P198`；
- 类型标识「笔记」。

### F5 — 定位行为

点击右栏卡片后：

1. 确保仍处于 PDF 阅读 Tab；
2. 向 PDFReader 发送定位通知；
3. PDFReader 跳转到对应页面；
4. 如果条目包含 bounds，则尝试滚动到选区附近；
5. 以 Toast 告知已定位页码。

### F6 — 数据刷新

右栏应响应以下变化：

- 打开 / 切换当前 PDF；
- 保存单词；
- 删除单词；
- 新增笔记；
- 删除 / 编辑笔记；
- 当前页变化。


### F7 — 笔记划线合并语义

通过阅读页「划线」创建笔记时，选区与已有笔记的关系按以下规则处理：

1. **完全相同选区**：视为 toggle，删除已有笔记和对应下划线。
2. **新选区完全位于已有笔记内部**：不创建新笔记，也不修改已有笔记。
3. **新选区与已有笔记部分重叠，且包含新增区域**：将新增区域并入已有选区，形成一条扩展后的笔记。
4. **无重叠**：创建新的独立笔记。


### F8 — 区分普通划线与笔记

阅读页选区菜单同时提供「划线」和「笔记」两个入口：

- 点击「划线」只添加 / toggle PDF 普通下划线，不弹出输入框，避免快速标记时打断阅读。
- 点击「笔记」才展示轻量输入框，用于填写自己的想法、理解、疑问或总结。
- 输入框展示当前选中文本，帮助用户确认笔记对象。
- 如果完全选中已有笔记划线，菜单额外提供「添加笔记」入口，用于向该笔记追加新的想法。
- 笔记内容按追加列表保存；同一条笔记划线可以累积多条想法。
- 内容可留空；留空时仅保存笔记划线和原文。
- 点击「保存」后，按 F7 的合并规则写入笔记。
- 点击「取消」不写入笔记，也不添加笔记下划线。

---

### F9 — AI 解释多轮追问

用户首次点击「解释」后仍沿用先提问再解释的流程；AI 返回解释后，气泡在解释内容下方继续展示追问输入框：

- 用户可以围绕同一选区继续提问，不需要重新选择原文。
- 后续请求携带当前问题、最近几轮问答和压缩后的较早上下文。
- 压缩策略先采用本地确定性摘要：保留最近 4 轮完整问答；更早轮次压缩为短摘要，并限制总上下文长度。
- 新一轮回答生成时，保留前文问答展示，当前回答以流式结果更新。
- 关闭解释气泡即结束本次临时对话；暂不持久化聊天记录。

## 6. 成功指标

- 阅读页中查看当前 PDF 单词 / 笔记无需切换 Tab。
- 点击右栏条目跳转成功率接近 100%。
- 右栏筛选响应无明显卡顿。
- 用户可一键隐藏右栏，避免影响纯阅读。
