# 书架

## 问题

文库是工具栏上的一份平铺列表，书只按最近打开排列。书多了以后找不到，也不能按文件夹把书放在一起。

## 用户行为

- 工具栏「文库」打开阅读区里的书架页，不新开窗口。没有打开 PDF 时，阅读区直接是书架。正在读的 PDF 留在底下，滚动位置还在。左侧目录和窗口分割的保存方式不变。
- 文件夹是书架。书架里可以再放书架或 PDF，一本书只待在一个地方。升级前已经在文库里的书留在「文库」根上，进度不变。
- 当前层只显示直接放在这一层的东西。书架和 PDF 按同一套顺序排在一起：PDF 是较大的封面，下面是书名和页码；找不到文件仍用橙色提示。子书架是带名字和册数的牌子，点进去才看到里面。
- 点 PDF 打开它并回到阅读。页头「返回阅读」回到进入书架前正在读的那本；当时没有打开的书就不显示。
- 可以新建、重命名、拖到另一个书架，也可以在当前层拖动排序。右键提供「移动到…」「重命名」「删除」。不能把一个书架放进自己或自己的子书架。同一层可以重名，空名字不行。
- 在某个书架里加入的书，落在当前这一层。人在阅读界面时用「打开 PDF」加入的书，落在文库根上。
- 导入文件夹时，在当前书架下建一个同名书架，把这一层的 PDF 放进去。勾选「包含子文件夹」时，子目录变成嵌套书架。已经在文库里的书留在原地。隐藏文件、包内文件和符号链接仍然不加入。
- 删除书架、删除一本书，以及根上的「清空」，都先确认。确认框写明书的数量（含子书架）、将删除的笔记条数和单词语境条数，并说明原来的文件还在。只删除这些书自己的笔记和单词语境。同一个单词在别的书里还有语境，那些语境还在。书库副本删除，副本上的划线随文件消失。正在读的书如果在删除范围内，关掉它，人留在上一层书架。
- 导入成功后的「撤回」只移出这次新加入的书，以及因此新建并且已经空了的书架，不删笔记和单词。
- 当前看的是哪一层只记在这次运行里。启动仍然打开上次的 PDF。

## 非目标

不把一本书同时放在多个书架上。不做成木纹贴图。不记住磁盘文件夹并在文件变化时再次扫描。不把翻译缓存删掉。

## 验收

1. 已有的书出现在文库根上，进度还在。新建书架后可以把书拖进去，也可以再放一个书架。
2. 点书打开并回到阅读；「返回阅读」回到原来那本。
3. 导入文件夹会得到同名书架；勾选包含子文件夹后，子目录是嵌套书架。已经在文库里的书不搬动。
4. 删除书架前能看到将删除的笔记和单词语境数量。同一单词在其他书里的语境还在。原文件还在，书库副本没有了。
5. 撤回导入不会删掉笔记和单词。
