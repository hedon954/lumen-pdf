# 设置窗口侧栏开关

## 问题

设置窗口此前使用系统 `Settings` 场景，工具栏样式默认走偏好设置风格，导致侧栏开关落位异常、缩放按钮受限，并在展开收起侧栏时出现明显卡顿。

## 用户行为

- 设置窗口采用与主阅读窗口一致的原生分栏样式：浮起式侧栏，侧栏开关位于标题栏内紧挨侧栏右上角，收起后留在红绿灯右侧可再次展开。
- 侧栏列表去掉「设置」分组标题，直接展示各设置项。
- 当前设置页标题（如「LLM 配置」「翻译设置」）在标题栏正中展示。
- 「保存设置」按钮位于窗口右下角。
- 红、黄、绿三个窗口控制按钮始终可见可用；可通过工具栏齿轮按钮或 `⌘,` 打开同一设置窗口。
- 展开与收起侧栏动画流畅。

## 非目标

不改各设置页的表单业务规则与主阅读窗口的目录逻辑。

## 验收

1. 打开设置，侧栏外观与主阅读窗口目录一致，无「设置」字样，红黄绿三个窗口按钮齐全，侧栏开关在标题栏侧栏右上角且无多余白底胶囊。
2. 当前页标题在标题栏正中，切换左侧菜单时同步更新。
3. 「保存设置」位于窗口右下角。
4. 点击侧栏开关收起与展开流畅，收起后开关仍在标题栏左侧可再次展开。
5. 菜单栏「设置…」及 `⌘,` 均可打开并聚焦该设置窗口。
