# LumenPDF — 阅读 AI 输入与选区操作优化 PRD

## 背景

本次迭代聚焦阅读场景中的三个摩擦点：单词解释缺少词源补充、跨页或页面交界处选区偶发不展示操作栏、AI 追问输入框只能单行输入且不便承载图片相关问题。

## 目标

1. 单词解释在适合时补充词源、历史故事或构词来源；该内容为可选，不要求每个单词强行生成。
2. 用户在页面交界处选择文本后，操作栏仍能稳定出现在可见窗口范围内。
3. AI 追问输入框支持多行输入：内容超过一行后自动增高，最多 10 行，超过后在输入框内部滚动。
4. AI 追问输入区提供图片附件入口，允许用户将图片内容随问题发送给支持多模态的 LLM。

## 非目标

- 本迭代会为词汇记录新增可选词源字段；不持久化图片附件。
- 本迭代不改变缓存写入与翻译回退流程；仅扩展单词缓存作用域，使提示词更新后不再复用旧模板生成的结果。

## 用户故事

- 作为英文阅读者，我希望解释单词时偶尔能看到词源或历史故事，以便更容易记忆。
- 作为 PDF 阅读者，我希望在页面底部或顶部跨页选择文本时，仍能看到翻译、解释、高亮、划线和笔记操作栏。
- 作为 AI 导读用户，我希望可以输入多行问题，并在问题较长时继续编辑末尾内容。
- 作为 AI 导读用户，我希望可以把图片作为追问的视觉上下文发送给 LLM。

## 功能需求

### FR1：单词词源补充

- 默认单词 prompt 要求模型通过独立的 `etymology` 字段，按需输出简短词源、历史故事或构词来源。
- 当词源信息不可靠或无助于理解时，模型应省略该小节。
- `TranslationResult`、UniFFI Swift 绑定和词汇记录新增 `etymology` 字段。
- 翻译卡片将「词源 / 历史故事」展示为与「语境翻译」「语境解释」「通用释义」分开的独立小块。
- 旧翻译缓存缺少该字段时按空字符串读取；旧词汇数据库通过幂等迁移新增默认空值列。
- `etymology` 允许为空；为空时翻译卡片不显示「词源 / 历史故事」小块。

### FR1.1：系统提示词版本更新

- 系统为内置单词提示词维护版本号。
- 应用启动时，如果用户当前模板仍是已知的旧内置模板，自动升级到新版并提示用户。
- 如果当前模板不是已知内置模板，视为用户自定义：不覆盖，在设置页提示有新版可用，并提供「保留自定义」和「使用新版」。
- 用户选择保留后，本次版本不再重复提醒；后续系统提示词再次升版时重新判断。
- 单词翻译缓存按目标语言和实际生效的 User/System Prompt 区分，避免模板升级后继续命中旧回答。

### FR2：页面交界选区操作栏

- 选区处理不应只依赖 `pdfView.currentPage`。
- 当 PDFKit 在页面交界处返回跨页选区时，应从 `selection.pages` 和逐行 selection bounds 中选择拥有最大有效选区面积的页面。
- 如果当前页也有有效选区几何，优先保持当前页，减少行为跳变。
- 操作栏锚点继续使用现有 SwiftUI 根坐标和窗口边界夹取策略。

### FR3：AI 多行追问输入

- 追问输入从单行 `TextField` 改为多行输入控件。
- 输入高度根据显式换行和估算换行自动增长。
- 输入框高度最多 10 行；超过 10 行后由输入控件内部滚动。
- 保持 loading 禁用、自动聚焦、发送按钮和默认键盘快捷行为。

### FR4：图片附件入口

- 输入区提供图片选择按钮。
- 支持一次选择多张图片，显示附件 chip 和删除按钮。
- 提交时读取图片原始内容，不压缩、不重新编码，通过 UniFFI 传给 Rust。
- Rust 使用 OpenAI-compatible 的图文 `content` 数组发送文本和 `data:` 图片 URL。
- 应用优先读取模型 metadata 判断输入模态；metadata 不含能力信息时，用内置极小图片做一次探测并按 Base URL + 模型缓存明确结果。
- 仅明确判定为不支持图片时将上传按钮置灰；认证、网络、限流等无法判断的状态保持可用。
- 未知状态下发送失败时，直接展示 LLM/网关返回的错误。
- 提交后清空附件列表。

## 验收标准

1. 默认单词 prompt 独立输出可为空的 `etymology`；非空时翻译卡片将其显示为单独的「词源 / 历史故事」小块。
2. 页面交界选区拥有有效几何时，`onTextSelected` 可收到非空 bounds、pageIndex 和操作栏锚点。
3. AI 输入框输入多行文本时高度逐步增长，超过 10 行后不继续撑高面板。
4. 明确不支持图片的模型会禁用上传按钮；支持或能力未知时可选择图片，提交后原图内容随请求发送并清空附件。
5. 旧缓存和旧数据库升级后仍可正常读取，已有词汇的词源字段默认为空。
6. 未修改的旧内置提示词自动升级；用户自定义提示词不被覆盖，并可在设置页选择是否使用新版。
