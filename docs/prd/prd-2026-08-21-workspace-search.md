# LumenPDF — 工作区搜索 PRD

## 1. 产品结论

阅读窗口必须能用 **⌘F** 打开一个类似 macOS 聚焦的搜索浮层，一次查找笔记、单词、划线、当前 PDF 原文，以及当前 AI 导读会话。选中结果后回到对应 PDF 位置；单词本和笔记页里的局部搜索框仍然保留。

## 2. 问题

笔记、单词、划线和 AI 回复散落在不同列表和 Inspector 里。用户已经知道某句原文或某条解释，却必须先猜它存在哪个入口，再在那个页面里搜。系统级 ⌘F 此前没有对应能力。

## 3. 功能需求

### F1 — ⌘F 打开工作区搜索

- 主阅读窗口按 ⌘F，或使用菜单「查找…」，弹出搜索浮层。
- 浮层出现在分栏的共同祖先上，盖住目录、PDF、Inspector，不被某一列裁切。
- 弹出时输入框获得键盘焦点。已打开时再次 ⌘F 仍聚焦输入框，不另开一份。
- 设置窗口不提供这套工作区搜索；不把搜索做成独立 `NSPanel`。

### F2 — 可搜索的内容

空查询不列出任何结果。输入关键词后，在启用的类别中匹配：

| 类别 | 搜索范围 | 打开结果 |
| --- | --- | --- |
| 原文 | 当前打开 PDF 的正文 | 跳到所在页，并尽量点亮匹配文本 |
| 单词 | 词条、音标、释义、语境翻译、语境解释、词源、例句 | 打开对应 PDF，跳到选区，右侧切到单词 |
| 笔记 | 用户笔记正文，以及该划线对应的原文 | 打开对应 PDF，跳到选区，右侧切到笔记 |
| 划线 | 当前 PDF 中自由高亮/下划线的原文（从 PDF 按位置取出） | 打开当前 PDF，跳到该标注 |
| AI 解释 | 当前导读会话里已写出的提问与回复 | 跳到该选区，右侧切到 AI |

- 单词和笔记覆盖文库里已保存的全部条目，不限于当前 PDF。
- 原文和自由划线只覆盖**当前打开**的 PDF；没有打开 PDF 时这两类没有结果。
- 已保存到笔记的 AI 回复按笔记检索；未保存的只存在于当前导读会话。
- 匹配不区分大小写；多个词按空格拆分后须全部命中。

### F3 — 外观与类别按钮

- 搜索条是胶囊形，使用系统材质与轻阴影，左侧放大镜，占位符为「搜索笔记、单词、划线…」。
- 右侧五个圆形按钮分别对应原文、单词、笔记、划线、AI 解释，默认全部开启。
- 点击圆形按钮切换该类是否参与搜索；至少保留一类开启。
- 结果列表出现在搜索条下方，展示类别、标题、匹配摘要、PDF 名与页码。

### F4 — 键盘与关闭

- ↑ / ↓ 移动高亮结果，Return 打开当前项，Esc 关闭。
- 点击浮层外的变暗区域关闭。
- 关闭后不记住本次查询，也不写入阅读恢复状态。

## 4. 非目标

- 不索引尚未打开的 PDF 全文，也不做跨文件原文检索。
- 不持久化完整 AI 对话历史；关闭导读会话后，未保存内容不再可搜。
- 不替换单词本、笔记页现有的页内搜索框。
- 不在设置窗口劫持 ⌘F。

## 5. 验收标准

1. 主窗口 ⌘F 弹出聚焦风格搜索条，输入框可立即键入。
2. 能分别搜到笔记正文、单词释义、当前 PDF 原文、当前页自由划线文本、当前 AI 回复。
3. 圆形按钮可把结果限制到单一类别。
4. 选中笔记/单词/划线/原文/AI 结果后进入阅读页并落到对应页；有选区的会点亮该处。
5. Esc 或点外侧关闭浮层；再次打开时输入框是空的。
