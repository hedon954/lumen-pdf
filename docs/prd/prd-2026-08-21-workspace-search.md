# LumenPDF — 工作区搜索 PRD

## 1. 产品结论

阅读窗口必须能用 **⌘F** 打开一个类似 macOS 聚焦的搜索浮层。默认只搜笔记和划线，需要时再打开单词、原文或当前 AI 导读。选中结果后回到对应 PDF 位置；单词本和笔记页里的局部搜索框仍然保留。

## 2. 问题

笔记、单词、划线和 AI 回复散落在不同列表和 Inspector 里。用户已经知道某句原文或某条解释，却必须先猜它存在哪个入口，再在那个页面里搜。系统级 ⌘F 此前没有对应能力。

## 3. 功能需求

### F1 — ⌘F 打开工作区搜索

- 主阅读窗口按 ⌘F，或使用菜单「查找…」，弹出搜索浮层。
- 浮层出现在分栏的共同祖先上，盖住目录、PDF、Inspector，不被某一列裁切。
- 弹出时输入框获得键盘焦点。已打开时再次 ⌘F 仍聚焦输入框，不另开一份。
- 设置窗口不提供这套工作区搜索；不把搜索做成独立 `NSPanel`。

### F2 — 可搜索的内容

空查询或不足两个字符的查询不列出任何结果。输入关键词后，只在**当前启用**的类别中匹配：

| 类别 | 默认 | 搜索范围 | 打开结果 |
| --- | --- | --- | --- |
| 笔记 | 开 | 用户笔记正文，以及该划线对应的原文 | 打开对应 PDF，跳到选区，右侧切到笔记 |
| 划线 | 开 | 当前 PDF 中自由高亮/下划线的原文（从 PDF 按位置取出） | 打开当前 PDF，跳到该标注 |
| 单词 | 关 | 词条、音标、语境翻译、通用释义；查询较长时才看语境解释、词源和例句 | 打开对应 PDF，跳到选区，右侧切到单词 |
| 原文 | 关 | 当前打开 PDF 的正文 | 跳到所在页，并尽量点亮匹配文本 |
| AI | 关 | 当前导读会话里已写出的提问与回复 | 跳到该选区，右侧切到 AI |

- 弹出时只索引默认类别；点开「单词 / 原文 / AI」后才加载对应数据，避免一打开就扫整本 PDF。
- 单词和笔记覆盖文库里已保存的全部条目，不限于当前 PDF。
- 原文和自由划线只覆盖**当前打开**的 PDF；没有打开 PDF 时这两类没有结果。
- 已保存到笔记的 AI 回复按笔记检索；未保存的只存在于当前导读会话。
- 匹配不区分大小写；多个词按空格拆分后须全部命中。不足两个字符的查询（例如单独一个「我」）不给出结果。

### F3 — 外观与类别按钮

- 搜索浮层在阅读窗口水平、垂直居中，不贴在工具栏下方。
- 搜索条独占一行，胶囊形，高度约 52pt、最大宽度约 720pt；扁平浅底、细描边和轻阴影，不使用明显渐变或凸起材质。左侧放大镜，占位符为「搜索笔记、划线…」。
- 搜索条下方居中排列带文字的胶囊开关：「笔记」「划线」「单词」「原文」「AI」。默认「笔记」「划线」开启。
- 点击开关切换该类是否参与搜索；至少保留一类开启。未开启的类别不出现在结果里。
- 结果列表出现在类别开关下方，每条用文字标明类别，并展示标题、匹配摘要、PDF 名与页码。

### F4 — 键盘与关闭

- ↑ / ↓ 移动高亮结果，Return 打开当前项，Esc 关闭。
- 点击浮层外的变暗区域关闭。
- 关闭后不记住本次查询，也不写入阅读恢复状态。

## 4. 非目标

- 不索引尚未打开的 PDF 全文，也不做跨文件原文检索。
- 不持久化完整 AI 对话历史；关闭导读会话后，未保存内容不再可搜。
- 不替换单词本、笔记页现有的页内搜索框。
- 不在设置窗口劫持 ⌘F。

## 5. 验收标准

1. 主窗口 ⌘F 在窗口中央弹出较大的扁平搜索条，输入框可立即键入。
2. 默认只搜笔记和划线；打开「单词」「原文」后才能命中这两类。
3. 类别按钮带文字，可把结果限制到已开启的类别。
4. 单个汉字或单字母查询没有结果。
5. 选中笔记/单词/划线/原文/AI 结果后进入阅读页并落到对应页；有选区的会点亮该处。
6. Esc 或点外侧关闭浮层；再次打开时输入框是空的。
