# LumenPDF — 划线入口、选词语境与阅读位置 PRD

## 1. 产品结论

一次划线只有一个笔记入口。选中单词时，原文语境使用页面上看得见的那一句；这一句如果短到几乎只有该词，或句子就从该词开头，则带上相邻句子。关闭应用后再打开，回到关闭前正在看的那一页，不能退回更早读过的页。Extra Config 当前行的高亮和该行文字对齐。目录里同一时刻只高亮一个章节。

## 2. 问题

跨行划线的每一行都出现一个笔记按钮。选中页面上明明有前后文的单词时，浮窗里的原文语境只剩该词，解释会说缺少上下文。阅读位置会回退：停在较后的页、滑到更后的页后立刻关闭，下次却打开更早的页。设置里 Extra Config 的当前行高亮和文字不在同一行。目录会同时高亮同一页上的两个章节。

## 3. 功能需求

### F1 — 一条划线一个笔记按钮

- 一次划出的连续多行只显示一个笔记按钮，放在这段划线的末端空白处。
- 已经按行拆开保存的旧划线，只要行与行紧挨着，仍然只显示一个按钮。
- 中间空开一段的两条划线各自保留按钮。
- 跨页划线仍是每一页一个入口。后续修订：跨页同一段划线只保留一个按钮，空笔记不再显示入口，见 [prd-2026-11-24-note-overlay-update.md](prd-2026-11-24-note-overlay-update.md)。

### F2 — 选词要带上看得见的语境

- 单词翻译的原文语境取自该词所在页面上的可见句子，而不是只发送单词本身。
- 这一句前后还有紧挨着的文字，且该句几乎只有被选中的词，或句子从该词开头时，原文语境带上相邻句子。后续修订：只补全选区碰到的那一句，不再并入没有碰到的相邻句，见 [prd-2026-11-26-selection-span.md](prd-2026-11-26-selection-span.md)。
- 离正文有明显间隔的标题不算进这句语境。后续修订：同一句的句首词必须保留，见 [prd-2026-11-25-notes-context-grammar.md](prd-2026-11-25-notes-context-grammar.md)。

### F3 — 关闭后回到最后阅读的位置

- 滚动到新的一页后立刻关闭应用，下次打开仍是关闭前可见的那一页，不能退回这次打开之前的页。
- 用户自己往回翻时，保存回翻后的位置。
- 重新打开时按可见文字所在的页定位，不用更早一次记录的页码盖过它。

### F4 — Extra Config 当前行对齐

- Extra Config 编辑器的当前行高亮与该行文字、行号处在同一行。

### F5 — 目录跟着阅读线

- 左侧目录的当前项继续用原来的浅色底和强调色文字，不改目录外观。
- 当前条是阅读线已经到达的最后一条书签。阅读线在可见区域从上往下三分之一处，不是视口顶边，也不是底边。顶边经常还留着上一节的末尾，底边又会把刚露出来的下一节提前算进来。
- 书签的位置用它自己的目的页和页内高度。没有垂直目标的书签从该页顶部算起。
- 还在阅读线下方的书签不高亮。阅读线进入下一页后，高亮上一页中最后开始的那条。

### F6 — 翻译选区标记

- 打开翻译浮窗时，选中的文字用和 macOS 预览相同的荧光笔：系统黄色，正片叠底，纸变黄、字保持黑色。
- 不画成带阴影的实色黄块。后续修订：临时选区改为与已保存黄高亮不同的浮起外观，见 [prd-2026-11-25-notes-context-grammar.md](prd-2026-11-25-notes-context-grammar.md)。
- 关闭翻译后标记消失，不写入 PDF。

## 4. 非目标

- 不改变划线的红色、合并规则或笔记正文。
- 不把整页正文都发给翻译模型。
- 不改窗口尺寸、分栏宽度的恢复规则。

## 5. 验收标准

1. 一次划过连续三行，页面上只有一个笔记按钮。
2. 选中一句中间的单词，原文语境包含该句里该词前后的文字，而不是只有这个词。
3. 停在某一页，滑到后面的页后马上关闭，再次打开仍在后面的那一页。
4. Extra Config 里移动光标，高亮条落在当前行文字上。
5. 新标题已经进入可见区域的上三分之一时，目录改为这一条；只在顶边残留上一节的几行时，不再停在上一节。只在底边露出的下一条还不高亮。没有垂直目标的书签按页首处理。
