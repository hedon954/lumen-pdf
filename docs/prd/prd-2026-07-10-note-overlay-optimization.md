# LumenPDF — 笔记浮层与划线回顾优化 PRD

**版本**: v1.0.15 · **日期**: 2026-07-10

## 1. 背景与问题

用户在 PDF 阅读页使用「笔记 / 划线笔记 / AI 导读」时，目前仍存在 3 个影响阅读连续性的交互问题：

1. **添加笔记浮层默认遮挡被划线句子**：用户选中文本后打开「添加笔记」浮层，浮层经常覆盖选区或紧贴选区，导致用户无法一边看原文一边输入笔记。
2. **添加笔记浮层无法拖动避让**：当默认位置不理想时，用户没有办法把浮层移到不遮挡的位置，只能关闭或改变阅读位置。
3. **长内容导读 / 解释浮层无法上下滚动**：当解释内容超长时，浮层内部内容被截断，用户无法通过滚动查看完整原文、译文、拆解或后续内容。
4. **已有笔记缺少原文快捷入口**：PDF 中存在笔记划线时，用户只能看到划线样式，缺少一个稳定、可点击的图标来快速打开该笔记，回顾成本较高。

## 2. 产品目标

1. 添加笔记时默认不遮挡当前选区文本。
2. 添加笔记浮层支持拖动，并能在窗口内保持可见。
3. 所有可能超高的阅读辅助浮层必须支持内部滚动。
4. 已有笔记在 PDF 原文旁提供轻量图标入口，点击即可快速打开笔记内容。
5. 保持 macOS 原生、轻量、低打扰的阅读体验，不引入复杂面板或重型编辑器。

## 3. 非目标

- 不改变笔记的数据库结构。
- 不改变笔记内容格式、Markdown 存储方式或导出格式。
- 不重做整个阅读 Inspector。
- 不新增完整的 PDF 批注侧栏。
- 不改变「划线」「高亮」「翻译」「解释」等动作的语义。
- 不在本迭代实现复杂的笔记编辑、标签、筛选或全文搜索。

## 4. 用户故事

### US1 — 添加笔记时保持原文可见

作为阅读用户，我选中一句话并添加笔记时，希望笔记输入框默认出现在选区附近但不遮挡选区，这样我可以边看原文边写笔记。

### US2 — 手动拖动笔记浮层

作为阅读用户，如果笔记浮层仍挡住我想看的内容，我希望可以拖动浮层到合适位置，并且浮层不会被拖出窗口导致找不到。

### US3 — 长解释内容可滚动

作为阅读用户，当 AI 解释、翻译或句子拆解内容很长时，我希望可以在浮层内部上下滚动，看到完整内容，而不是只能看到顶部内容。

### US4 — 从 PDF 原文快速打开已有笔记

作为复习用户，当 PDF 中某段文字已经有笔记时，我希望在划线附近看到一个不打扰阅读的小图标，点击后直接弹出对应笔记，方便回顾。

## 5. 功能需求

### F1 — 添加笔记浮层默认避让选区

- 打开添加笔记浮层时，系统应基于当前 PDF 选区在窗口坐标中的位置计算浮层位置。
- 浮层优先出现在选区下方或右下方，并与选区保持至少 12pt 间距。
- 如果下方空间不足，浮层应自动放到选区上方。
- 如果上下都不足，应选择遮挡面积最小的位置，并确保主要输入区可见。
- 浮层不得默认覆盖当前选区的主体文本区域。
- 多行选区应以选区整体 bounding rect 作为避让对象。

### F2 — 添加笔记浮层可拖动

- 添加笔记浮层标题栏区域支持拖动。
- 拖动时浮层应跟随鼠标移动，体验接近 macOS 浮层 / popover。
- 拖动结束后，浮层位置在当前草稿会话内保持。
- 拖动边界应限制在阅读窗口可见区域内，至少保留 32pt 可点击区域。
- 重新打开新的添加笔记草稿时，默认位置重新根据新选区计算，不沿用上一次手动拖动位置。
- 拖动不应影响 PDF 选区、滚动、缩放或保存笔记动作。

### F3 — 超长内容浮层支持内部滚动

- 添加笔记浮层、笔记回顾浮层、AI 解释 / 导读浮层中所有可能超过可视高度的内容区必须放入滚动容器。
- 浮层最大高度不超过阅读窗口高度的 70%，并保留窗口边缘安全间距。
- 当内容短于最大高度时，不显示多余滚动区域，保持紧凑。
- 当内容超过最大高度时，用户可通过触控板、鼠标滚轮或滚动条上下查看完整内容。
- 底部主操作按钮（取消、保存、关闭等）应固定在浮层底部，不随正文内容滚走。
- 滚动状态不应导致输入框失焦或误触发 PDF 页面滚动。

### F4 — 已有笔记图标入口

- 对每条笔记划线，在原文附近显示一个轻量图标入口。
- 图标建议使用系统符号 `note.text` 或 `note.text.badge.plus`，尺寸约 14–18pt。
- 图标应靠近对应划线末端或行尾，不覆盖正文主要字形。
- 多行划线优先把图标放在最后一行末端。
- 图标仅用于表示「这里有笔记」，不替代红色划线本身。
- 鼠标悬停图标时应有可点击反馈，例如轻微背景、颜色变化或 tooltip。
- 点击图标后弹出笔记回顾浮层，展示：
  - 原文选区。
  - 当前笔记内容。
  - 创建时间（如已有数据可用）。
  - 关闭按钮。
- 如果同一选区下有多条笔记，回顾浮层应按创建时间展示列表。
- 点击图标不应修改笔记内容，也不应创建新笔记。

### F5 — 笔记回顾浮层行为

- 笔记回顾浮层也应默认避让原文，并支持拖动。
- 回顾浮层内容超长时必须支持内部滚动。
- 回顾浮层应提供「打开右侧笔记」入口：如果阅读 Inspector 已存在，可切换到笔记页并定位到该笔记；如果本迭代定位成本过高，可先只切换到笔记页。
- 点击浮层外部或关闭按钮可以关闭回顾浮层。
- 关闭回顾浮层不应清除 PDF 当前阅读位置。

## 6. 交互规则

### 6.1 默认定位优先级

1. 选区下方，不遮挡选区。
2. 选区上方，不遮挡选区。
3. 选区右侧或左侧，不遮挡选区。
4. 窗口内遮挡面积最小的位置。

### 6.2 拖动规则

- 仅标题栏 / 顶部区域响应拖动。
- 文本输入、按钮、滚动内容区不触发拖动。
- 拖动时不关闭浮层。
- 拖动后如果窗口大小变化，应重新 clamp 到可见区域。

### 6.3 滚动规则

- 浮层内容区优先消费滚轮事件。
- 内容区滚动到顶部 / 底部后，不应立刻把滚动传给 PDF 页面造成误滚。
- 对 TextEditor 输入区，内部滚动优先于外层浮层滚动。

## 7. 视觉要求

- 浮层样式延续现有轻量毛玻璃 / 圆角风格。
- 新增图标必须克制，不形成密集噪点。
- 图标颜色建议使用系统蓝色或 secondary，并在 hover 时增强。
- 不使用大面积阴影、强烈色块或会干扰阅读的动画。
- 浮层宽度可沿用现有添加笔记宽度，建议 360–420pt。

## 8. 验收标准

1. 在截图 1 场景中，打开「添加笔记」后，浮层默认不遮挡被划线句子主体。
2. 用户可拖动「添加笔记」浮层到页面任意可见区域，拖动后仍可保存或取消。
3. 在截图 3 场景中，超长解释 / 导读内容可以在浮层内部上下滚动到底部。
4. 对已有笔记划线，PDF 原文旁显示可点击图标；点击后能快速弹出笔记内容。
5. 多页、多行、窗口缩放、Inspector 显示 / 隐藏时，浮层和图标仍保持可见且不崩溃。
6. 保存、追加、删除笔记后，图标状态能及时刷新。
