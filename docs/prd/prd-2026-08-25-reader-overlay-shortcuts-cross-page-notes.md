# LumenPDF — 阅读浮层快捷入口与跨页笔记划线 PRD

## 1. 产品结论

工作区搜索需要用轻微、小半径的背景失焦把搜索内容和 PDF 正文分层，同时保留正文与侧栏的可辨识层级。翻译成功后，用户可直接从翻译浮窗进入当前选区的 AI 解释。笔记关联划线与自由划线必须消费同一份逐页选区，跨页选择后每一页都要正确落笔并在重启后保留。

## 2. 功能需求

### F1 — 搜索浮窗对比度

- 打开工作区搜索后，PDF、目录和 Inspector 背景整体增加轻微、小半径的失焦，并叠加明暗遮罩；背景内容仍应可辨，不得退化成无法识别的色块。
- 搜索条、类别按钮和结果卡片继续使用系统自适应材质；浅色、深色外观下都不能让正文穿透到影响搜索文字辨识。
- 保留既有的居中位置、点击外侧关闭、键盘导航和类别筛选行为。

### F2 — 翻译后的 AI 解释快捷入口

- 翻译成功且生成结束后，在 footer 的「保存到笔记 / 保存到单词本」左侧显示「AI 解释」。后续修订：footer 左侧增加「拷贝译文」，「AI 解释」仍在保存动作左侧，见 [prd-2026-09-01-native-translation-popover.md](prd-2026-09-01-native-translation-popover.md)。
- 点击后关闭翻译浮窗，用同一个原文选区、上下文、页码和完整跨页几何打开右侧 AI 导读。
- 翻译进行中、完全失败或没有有效内容时不显示该入口。
- 该入口只是缩短路径，不改变 AI 解释的提示词、追问、保存和失败重试规则。

### F3 — 跨页笔记划线

- 自由高亮、自由划线、手写笔记、句子翻译保存到笔记、AI 解释保存到笔记，都使用选区生成的同一组逐页正文标记。
- 跨页选区创建笔记后，每个包含正文的页面都显示红色笔记划线；已过滤的重复页眉页脚不得重新出现。
- 跨页几何随笔记持久化；关闭并重新打开 PDF 后，各页划线仍完整恢复。
- 删除笔记时移除该笔记在所有页面上的划线。合并、撤销和重做不能只处理主页面。后续修订：撤回历史容量、Redo、文档生命周期与笔记快照事务见 [prd-2026-08-26-annotation-undo-history.md](prd-2026-08-26-annotation-undo-history.md)。
- 历史单页笔记无需迁移用户内容，仍按原页码和矩形恢复。

## 3. 非目标

- 不把自由划线和笔记合并成同一种数据或相同的删除语义。
- 不改变笔记在列表、Inspector 和搜索结果中以一个主页面定位的行为。
- 不为历史单页笔记推断不存在的跨页选区。

## 4. 验收标准

1. 在浅色和深色外观打开 ⌘F，背景正文有轻微失焦但仍可辨识，搜索条和类别文字清晰可读。
2. 句子或单词翻译成功后，「AI 解释」位于保存动作左侧；点击后翻译浮窗关闭，右侧导读显示相同选区。
3. 选择相邻两页正文并添加笔记，两页均出现笔记划线，重复页眉页脚不被划入。
4. 退出并重新打开应用或 PDF，跨页笔记划线仍覆盖原来的各页正文。
5. 删除跨页笔记后，各页关联划线全部消失；历史单页笔记仍可正常显示和删除。
