# LumenPDF — 阅读 Inspector PRD

**版本**: v1.0.13 · **日期**: 2026-07-03

## 1. 产品结论

LumenPDF 的下一步是把阅读现场收敛成一个稳定、简洁的三栏体验：左侧目录，中间 PDF，右侧阅读 Inspector。AI 导读从悬浮窗口迁入右侧 Inspector，减少遮挡、拖拽、缩放和滚动状态带来的复杂度。

PDF 始终是主画布；Inspector 只承载当前阅读上下文、当前选区导读和当前文档笔记。

## 2. 目标

1. 降低悬浮窗口带来的遮挡和交互冲突。
2. 让 AI 导读、单词、笔记都回到同一个右侧阅读辅助区。
3. 保持 macOS 原生、安静、精致的阅读质感。
4. 让用户在不离开 PDF 的情况下完成理解、追问和沉淀。
5. 为后续代码拆分建立清晰产品边界。

## 3. 非目标

- 不做全局聊天页。
- 不持久化完整 AI 对话历史。
- 不替代顶部「单词本」「笔记」管理页。
- 不新增数据库迁移。
- 不在右栏加入复杂批量管理、导出、排序配置。

## 4. 信息架构

阅读页由三部分组成：

```text
┌──────────┬──────────────────────────────┬──────────────────────┐
│ 目录      │ PDF 阅读区                    │ 阅读 Inspector        │
│          │                              │ 上下文 / 导读 / 笔记   │
└──────────┴──────────────────────────────┴──────────────────────┘
```

右侧 Inspector 顶部提供三个模式：

- **上下文**：当前 PDF 的单词与近期笔记概览。
- **导读**：当前选区的 AI 解释、追问和保存。
- **笔记**：当前 PDF 的笔记列表，按页码和选区分组。

## 5. 交互需求

### F1 — Inspector 容器

- Inspector 固定在 PDF 阅读区右侧，不以浮层覆盖正文。
- 默认宽度适合长文本阅读，建议 340–380pt。
- 支持通过系统 split handle 调整宽度，宽度限制在 300–460pt。
- 可通过工具栏按钮显示 / 隐藏。
- 显示 / 隐藏或调整宽度时，PDF 应保持当前页码和页内位置。

### F2 — 视觉风格

- 整体样式遵循 macOS 原生应用：轻背景、细分隔线、适度留白、清晰层级。
- 不使用厚重阴影、大面积渐变、复杂装饰或过多嵌套卡片。
- 卡片圆角保持克制，建议 8pt。
- 主操作使用系统蓝色；次要操作使用 plain / bordered；删除使用红色图标。
- 文本应有足够对比度，AI 回复和笔记内容不能过浅。
- 所有列表、按钮和输入框在窄宽度下不得挤压、重叠或截断关键文字。

### F3 — 上下文模式

- 展示当前 PDF 中与阅读位置相关的单词和笔记摘要。
- 默认定位到当前页附近。
- 条目显示类型、页码、核心内容和简短原文。
- 点击条目跳转到 PDF 原文选区并短暂聚焦。
- 该模式只做阅读辅助，不提供复杂编辑。

### F4 — 导读模式

- 用户在 PDF 中选中文本并点击「解释」后，Inspector 自动切换到「导读」。
- 导读顶部固定展示当前选区原文，可折叠。
- 用户可以先输入问题，也可以直接解释。
- AI 回复以消息流形式展示，支持 Markdown。
- 后续追问围绕同一选区继续，不要求重新选择原文。
- 流式输出只在用户停留在底部时自动跟随；用户向上阅读时不强制滚动。
- 输入框在进入导读模式和 AI 回复完成后自动聚焦。
- 每条 AI 回复可单独保存为笔记，也可一次保存全部未保存回复。
- 已保存回复显示明确状态；删除已保存回复时删除对应笔记。

### F5 — 笔记模式

- 展示当前 PDF 的全部笔记。
- 按页码分组，同一选区下的多条笔记分开展示并带创建时间。
- 笔记内容支持 Markdown。
- 卡片默认收起，展示原文和前几条内容；展开后显示完整笔记。
- 点击卡片跳转到 PDF 原文选区。
- MVP 中不在 Inspector 内做复杂编辑；编辑仍可在「笔记」管理页完成。

### F6 — 选区行为

- 「翻译」保留快速阅读场景，可以使用轻量结果浮层。
- 「解释」进入右侧 Inspector 的导读模式。
- 「划线」直接写入 PDF 标注，不打开导读或笔记面板。
- 「笔记」打开轻量笔记输入，不与导读混在一起。

### F7 — 状态保持

- Inspector 当前模式、显示状态和宽度应跨重启保存。
- 当前 PDF 切换后，Inspector 自动刷新上下文和笔记。
- 当前选区变化时，导读模式展示新的选区准备态。
- 关闭 Inspector 不丢失 PDF 阅读位置。

## 6. 空状态

- 未打开 PDF：不展示 Inspector。
- 上下文为空：展示简洁空状态，不占用过多空间。
- 导读无选区：提示用户选中文本后开始导读。
- 笔记为空：提示当前 PDF 尚无笔记。

空状态文案应短、直接，不写长说明。

## 7. 验收标准

- 点击「解释」后不再出现长期遮挡正文的悬浮聊天窗口。
- AI 导读在右侧 Inspector 中完成首问、追问、保存和删除。
- Inspector resize 使用系统级拖拽体验，鼠标样式正确。
- PDF 阅读位置在 Inspector 显示 / 隐藏 / 调整宽度后保持稳定。
- 上下文和笔记列表清晰、简洁、对比度足够。
- 同一选区的多条笔记分开展示，带时间，支持 Markdown。
- README 保持简洁；详细行为记录在 PRD/TDD。

## 8. 后续迭代

1. PDF 标注点击后自动切换 Inspector 到对应条目。
2. Inspector 内支持轻量编辑笔记。
3. 对当前章节聚合单词和笔记。
4. 支持保存导读会话摘要，而不是完整聊天记录。
