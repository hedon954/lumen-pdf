# 文库与阅读切换

## 问题

书架盖在阅读页上时，「PDF 阅读」仍然高亮，左侧目录也还在并高亮。点顶部标签或目录标题都不会离开书架，只能靠页头的「返回阅读」。书名和页码挤在同一个胶囊里，页码贴着胶囊下沿。封面被统一垫了一层底，书页比例不同时会露出一圈底色。

## 用户行为

- 顶部固定为「文库」「阅读」「单词」「笔记」。文库是其中一页，不再是旁边的一个按钮。
- 点「文库」打开当前书架，并收起左侧目录。目录原来是开着还是关着会被记住；回到阅读时按记住的状态恢复，而不是把这次收起写成新的偏好。
- 点一本 PDF，进入「阅读」，停在这本书上次的进度。点「阅读」，回到进文库之前正在看的那本，滚动位置还在。当时没有打开的书时，「阅读」仍停在文库。
- 点「单词」或「笔记」离开文库，显示对应列表。
- 书架页头不再放「返回阅读」，根上也不再写「文库」。进入某一层书架后，路径仍从「文库」点回根。新建、清空和加入还在。
- 正在阅读时，胶囊里的书名过长会从中间截断，页码留在胶囊里面。文库页不显示这本书名和页码。
- 每本书的格子一样大。封面按自己的比例放在格子里，不铺底色，也不再画一圈和格子一样大的边。书名紧挨在封面下面。页码和阅读时间在书名下一行，时间在右侧。不写「最近」：今天显示时刻，昨天显示「昨天」加时刻，今年显示月日，更早的带年份。
- 当前层按最近打开时间倒序，最近打开的排在前面。一本书用它自己的打开时间。一个书架用里面任意一本书里最晚的打开时间；里面还没有书时，用这个书架的创建时间。时间相同再按名字排。拖进另一个书架仍然是移动，同一层里拖动不再改变先后。
- 子书架仍是一块带名字和册数的牌子。

## 非目标

不改书架的嵌套、拖动、删除和导入规则。不把文库页记成下次启动要打开的标签；启动仍回到上次的阅读、单词或笔记，并打开上次的 PDF。

## 验收

1. 在阅读中点「文库」，「文库」高亮，目录收起，点目录标题不会发生。再点「阅读」，回到刚才那本和刚才的位置，目录恢复原状。
2. 在文库里点另一本，进入阅读并停在那本的进度。
3. 没有打开 PDF 时，阅读区是文库，「阅读」不会变成一个空白页。
4. 长文件名下，页码完整留在胶囊内。
5. 封面周围没有统一的底色边。书名在封面下，页码和阅读时间在书名下一行，时间在右侧。
