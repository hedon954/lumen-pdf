# LumenPDF — 阅读位置恢复与浮窗拖动 PRD

## 1. 产品结论

v1.0.20 修复两类阅读连续性体验问题：

1. 重新打开应用或文档时，阅读位置偶尔落在上次关闭位置之前的几页，而不是精确回到关闭时的可见区域。
2. 翻译等窗口型浮层遮挡正文时，用户需要能按住明确的移动手柄拖开；关闭按钮与点击浮层外部必须可靠关闭浮层。后续修订：翻译采用 Look Up 式实色锚定外观，并继续保留本迭代的移动手柄和点外关闭，见 [prd-2026-09-01-native-translation-popover.md](prd-2026-09-01-native-translation-popover.md)。

本版本不新增独立产品能力，而是把「回到上次读到的地方」和「浮层可挪开、可关掉」收敛为稳定、可预期的行为。

## 2. 背景与问题

### 2.1 阅读位置漂移

此前系统把阅读位置主要存成可视区域相对文档总高度的比例。启动时窗口尺寸、分栏宽度和自动缩放仍会继续变化，PDFKit 重排后同一比例会指向不同内容，表现为偶发回到前几页。

用户期望：退出或切换文档前停在哪一行附近，再次打开后仍停在同一行附近，而不是同一相对页百分比。

### 2.2 浮层拖动与关闭

翻译浮层右上角的四向箭头在视觉上是移动手柄，但此前只是装饰图标；拖动逻辑挂在标题栏背景上，按住该图标并不能拖动。随后又出现点击关闭按钮、点击浮层外部无法关闭的问题，打断翻译与笔记工作流。

用户期望：

- 按住四向箭头拖动，即可移动浮层。
- 点击 `×` 或浮层外的阅读区域，浮层立即关闭。
- 朗读、保存等其他按钮不受影响。

## 3. 产品目标

1. 重开文档后，可见阅读区域与关闭前一致（同一页附近的同一段文字），缩放与横向位置一并恢复。
2. 窗口型阅读浮层提供明确的移动手柄；按住手柄拖动即可在阅读区内调整位置。
3. 浮层关闭路径可靠：关闭按钮、配置了点外关闭的浮层背景点击都必须生效。
4. 不改变翻译内容、保存单词、发音、笔记写入和 LLM fallback 行为。

## 4. 非目标

- 不修改数据库 schema 或 SQLite 中的 `last_page` / `last_scroll_offset` 语义以外的字段结构。
- 不引入跨设备同步阅读进度。
- 不把选择快捷操作条改成窗口型浮层。
- 不重做浮层视觉风格或翻译内容结构。
- 不在本版本解决所有 PDFKit 布局抖动的极端场景；以「关闭前可见文本」为准。

## 5. 功能需求

### F1 — 精确恢复阅读位置

- 应用退出、窗口最小化前、文档切换时，必须保存当前可见阅读位置。
- 再次打开同一文档时，应恢复到关闭前可见区域对应的文本位置，而不是仅恢复页码或文档高度比例。
- 自动缩放或窗口/分栏尺寸在启动后发生变化时，恢复结果仍应落在同一段文字附近。
- 用户一旦开始主动滚动，或执行目录/页码/笔记定位等显式跳转，系统应立即停止继续“纠正”到旧位置，并记录新位置。

### F2 — 浮层移动手柄

- 翻译浮层、添加/追加笔记浮层、笔记回顾浮层均提供统一的移动手柄。后续修订：翻译移动手柄与播放、刷新、关闭组成四个等大紧凑按钮并整体右对齐；其余笔记浮层保持本条，见 [prd-2026-09-01-native-translation-popover.md](prd-2026-09-01-native-translation-popover.md)。
- 手柄外观继续使用四向箭头，并位于标题栏操作区（关闭按钮附近）。
- 按住手柄拖动时，浮层跟随指针移动，并限制在当前阅读可见区域内。
- 松手后浮层停留在用户放下的位置，直到关闭或打开下一次浮层。

### F3 — 浮层关闭

- 点击关闭按钮必须关闭当前浮层。
- 对配置了点外关闭的浮层（如翻译、笔记回顾），点击浮层外的阅读区域必须关闭。
- 点击浮层内部正文、标题、按钮不得误触发关闭。
- 缩放热区不得覆盖关闭按钮或移动手柄。

## 6. 验收标准

1. 在文档中部阅读后退出并重开，可见区域与退出前一致；连续多次退出重开结果稳定。
2. 调整窗口大小或侧栏宽度后退出重开，仍回到同一段文字附近。
3. 打开翻译浮层后，按住四向箭头可拖动；朗读与保存按钮仍可用。
4. 点击 `×` 可关闭；点击浮层外可关闭翻译浮层。
5. 最小化再还原后，阅读位置不丢失到文档开头或前几页。

## 7. 风险与说明

- 阅读位置恢复依赖 PDFKit 内部布局时序；实现上允许在布局稳定前多次对齐，但不得在用户主动滚动后继续拉回旧位置。
- 旧版本仅保存比例坐标的安装，首次升级后仍可回退到比例恢复；产生新锚点后的后续恢复应更精确。
- 本版本的 UI 交互修复需要在真实 macOS 运行时验证；仅编译通过不能视为验收完成。
