# LumenPDF — 标注撤回历史 PRD

## 1. 产品结论

阅读标注使用 macOS 标准的撤回 / 重做交互。系统保留最近 50 个用户级操作，满足至少 20 条历史的要求；一次跨页标注只算一个操作。撤回必须同时恢复可见标注和本地持久化数据，不能只改当前 PDF 画面。

## 2. 功能需求

### F1 — 撤回与重做范围

- ⌘Z 撤回最近一次自由高亮、自由划线、笔记新增、笔记合并或笔记删除。
- ⇧⌘Z 重做最近一次已撤回操作；执行新的可撤回操作后，旧 Redo 分支失效。
- 手写笔记、翻译保存到笔记和 AI 解释保存到笔记使用相同的笔记撤回语义。
- 单词本高亮继续随单词记录增删，不混入阅读标注历史。

### F2 — 历史容量与分组

- 主窗口保留最近 50 个顶层撤回操作，不少于 20 个。
- 同一次用户操作即使覆盖多页、多个矩形或合并多条旧笔记，也只占一个历史项；一次撤回整体恢复，不能逐页拆开。
- 历史只属于当前打开 PDF 的本次阅读上下文。切换 PDF、关闭阅读器或退出应用后，不允许再撤回去修改旧文档；历史不跨重启持久化。

### F3 — 焦点与系统交互

- 光标位于笔记编辑器、搜索框或其他文本输入框时，⌘Z / ⇧⌘Z 优先撤回 / 重做文本编辑，不得误删 PDF 标注。
- PDF 阅读区是当前交互对象时，快捷键和「编辑」菜单操作同一份标注历史，并显示「撤销/重做 高亮」「撤销/重做 划线」「撤销/重做 划线笔记」或「撤销/重做 删除笔记」等系统动作名称。

### F4 — 数据一致性

- 自由标注撤回 / 重做后立即更新本地标注存储，重新打开 PDF 时结果一致。
- 笔记撤回 / 重做必须原样保留笔记 ID、创建时间、正文、用户笔记和完整跨页几何；合并前的多条笔记要整体恢复。
- 笔记数据库切换失败时，不改动当前可见标注，并向用户展示系统错误；不能出现 UI 已撤回但数据库仍是新状态的半成功结果。
- 从数据库恢复标注、打开 PDF 或刷新已有标注不得产生新的撤回历史。

## 3. 非目标

- 不把撤回历史写入 SQLite、`UserDefaults` 或阅读恢复状态。
- 不支持切换到另一份 PDF 后继续撤回上一份 PDF。
- 不把普通滚动、缩放、选区、搜索、翻译请求或 AI 对话纳入标注撤回历史。

## 4. 验收标准

1. 连续创建至少 20 次自由标注后，可按相反顺序逐次撤回，并可用 ⇧⌘Z 重做。
2. 一次跨两页的划线或笔记只需一次 ⌘Z 就完整移除，两页都同步变化；重做一次即完整恢复。
3. 合并多条笔记后撤回，原笔记 ID、顺序、正文和各页划线恢复；重做后不产生重复笔记。
4. 删除笔记后 ⌘Z 可恢复，⇧⌘Z 可再次删除；关闭并重开 PDF 后数据库和划线一致。
5. 撤回后执行新的标注，原 Redo 分支不可再执行。
6. 在笔记文本框中输入后按 ⌘Z，只撤回文字；切换 PDF 后 ⌘Z 不修改上一份 PDF。
