# 主题切换、PDF 深色阅读与翻译颜色设置

## 问题

长时间阅读 PDF 时，用户需要根据环境切换浅色或深色界面。深色界面下，PDF 页面和翻译浮层仍使用默认颜色，会产生刺眼的亮背景或低对比度文字。

## 用户行为

- 设置中提供「外观」选项：浅色、深色、跟随系统。选择立即生效，并在下次启动后保留。
- 选择深色或系统处于深色模式时，阅读器中的 PDF 页面显示为深色背景，原有深色文字自动调整为浅色，图片和版式保持可读。
- 设置的「翻译」页面提供「翻译颜色」选择器。用户可以选择翻译标签、译文和朗读按钮使用的颜色，选择立即应用并持久化。
- 翻译颜色由用户自行选择；默认值沿用现有翻译浮窗的粉色强调色。
- 切换外观或翻译颜色不会改变 PDF 文档内容、选区、标注、阅读位置或翻译结果。

## 非目标

- 不修改 PDF 文件本身，不重新写入页面内容或图片资源。
- 不增加单独的主题编辑器，不为每个翻译控件提供独立颜色配置。
- 不改变系统跟随模式下 macOS 外观的切换规则。

## 验收

1. 在设置中选择浅色、深色或跟随系统后，主窗口、设置页和翻译浮层立即使用对应外观。
2. 深色阅读时 PDF 页面背景为深色，页面文字清晰可辨，滚动、缩放、选区和标注仍可用。
3. 退出并重新打开应用后，外观选择和翻译颜色仍保持上次保存的值。
4. 修改翻译颜色后，翻译结果中的标签、译文和朗读按钮使用该颜色。
5. 关闭应用功能或打开已有 PDF 时，不会因为主题或颜色设置而修改文档数据。
