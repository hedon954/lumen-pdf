# 从文件夹导入 PDF

## 问题

文库只能一次打开一个 PDF。文件夹里有多份文献时，需要逐个选择才能出现在文库中。

## 用户行为

- 工具栏「打开 PDF」、文库弹层的加号、以及「文件」菜单，都可以打开单个 PDF，或导入一个文件夹。空状态同时提供「选择文件…」和「导入文件夹…」。
- 导入默认只加入所选文件夹这一层的 PDF。选择文件夹时可以勾选「包含子文件夹」，勾选后才会加入其中的子文件夹。隐藏文件、包内文件和符号链接不加入。
- 已经在文库中的文件保持原阅读进度和最近打开顺序，不会被再次打开。
- 导入不切换当前正在读的 PDF。新加入的文件排在文库最前面，进度为空，直到用户打开。已有文件之间的相对顺序不变。
- 文库弹层标题为「文库」。封面、文件名和阅读进度的展示方式不变。
- 导入结束后提示结果：新加入的数量；若有已在文库中的文件，一并说明；文件夹里没有 PDF 时说明没有可加入的文件；写入失败时说明未能加入的数量。这次确实加入了文件时，提示上有「撤回」，停留片刻后消失。撤回只把这次新加入的 PDF 移出文库；笔记和单词保留。若撤回时正在读其中一本，则关闭它。
- 文库弹层提供「清空」。确认后移出列表中的全部 PDF，不删除磁盘文件，也不删除笔记和单词。从笔记或单词再次打开已移出的 PDF 时，会重新打开该文件并加回文库。
- 从文库移除单本仍然只移出列表，不删除磁盘上的文件。

## 非目标

不记住文件夹，也不在启动或文件变化时再次扫描。不因为磁盘上的文件消失而自动移出文库。不把符号链接指向的 PDF 再加入一次。清空和撤回都不删除笔记、单词或磁盘文件。

## 验收

1. 不勾选「包含子文件夹」时，子文件夹里的 PDF 不进入文库；勾选后才会进入。当前打开的文档不变。
2. 再次导入同一文件夹时，已有文件的进度和排序不变，并提示这些 PDF 已在文库中。
3. 隐藏 PDF、符号链接和空文件夹不产生新的文库条目。
4. 导入后从文库打开新文件，可以读到该 PDF。点「撤回」后，这次新加入的文件离开文库，笔记仍在。
5. 清空文库后列表为空，笔记和单词还在；从笔记打开对应 PDF 会把它加回文库。
