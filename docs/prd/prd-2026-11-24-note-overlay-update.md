# 笔记入口、翻译浮窗与检查更新

## 问题

空白划线也会浮出笔记按钮，跨页同一段划线会出现两个入口。翻译浮窗拖不出应用窗口，点到别的应用就会关掉，footer 也不能给当前选区加高亮。菜单里点「检查更新」经常没有反馈，发布说明是生 Markdown，确认安装后新版本经常替不进去。

## 用户行为

- 只有真正写了内容的笔记才显示页面上的笔记按钮。空笔记、只有空白字符的笔记，以及尚未写笔记的自由划线，都不显示按钮。添加笔记仍然走选区操作栏。
- 同一段划线只显示一个按钮，跨页也是如此。连续阅读两页都看得见这段划线时，按钮在最后一页的末行；只看得见其中一页时，按钮落在那一页的末行。不相邻、互不重叠的划线仍各自保留按钮。
- 翻译浮窗 footer 在「AI 解释」左侧提供「高亮」；若该选区已经被自由高亮覆盖，则显示「取消高亮」。动作与选区操作栏的高亮相同，写入应用内标注，不是翻译选区的临时荧光笔。
- 阅读浮窗（翻译、添加笔记、回顾笔记）可以拖到应用窗口外面。初始仍挨着选区放置，不画指向选区的箭头。拖动手柄跟随屏幕上的鼠标位置，不再限制在阅读区域内。卡片边框不带投影。
- 选区操作栏点「笔记」或「添加笔记」必须立刻出现笔记输入框。点页面上的笔记按钮仍打开回顾浮窗。
- 点到其他应用或桌面时浮窗保持打开。只有点到 LumenPDF 自己窗口里、且不在该浮窗上的位置时才关闭。Escape 仍关闭。滚动或缩放 PDF 仍关闭翻译浮窗。
- 菜单或设置里点「检查更新」立即出现面板，并显示「正在检查更新」。已是最新、查询失败、发现新版本都在同一面板里说明，不再静默结束。后续修订：请求次数用完和连不上服务器分开说明，见 [prd-2026-11-25-update-rate-limit.md](prd-2026-11-25-update-rate-limit.md)。
- 更新说明按 Markdown 渲染标题、列表和强调，而不是原样显示 `###` 标记。
- 确认安装后，应用先写出阅读位置，再退出。一个已脱离本进程的助手等旧进程退出（必要时结束它），然后把当前 `.app` 换成新副本并重新打开。正在运行的应用不能自己覆盖自己的包，所以替换发生在退出之后。

## 非目标

不改笔记存储格式，不把选区操作栏也拖出窗口，不引入 Sparkle 或后台静默安装。

## 验收

1. 一页上有多条未写笔记的划线时，不出现笔记按钮；给其中一条写下内容后只出现一个按钮。
2. 跨页划线在单页视图和连续两页视图都只有一个按钮。
3. 翻译 footer 可高亮 / 取消高亮当前选区；关闭翻译后高亮仍在。
4. 把翻译浮窗拖到主窗口外仍可阅读被挡住的原文；拖动方向与鼠标一致；浮窗没有指向箭头；点到其他应用浮窗不关，点回 PDF 正文才关。
5. 划选文本后点操作栏「笔记」，输入框出现在选区旁，可输入并保存。
6. 菜单「检查更新…」立刻出现检查中状态；最新版本、失败和可用更新都有文字说明；发布说明里的标题和列表按 Markdown 显示。
7. 从「应用程序」里已安装的副本确认更新后，退出、替换、重新打开，笔记和阅读进度仍在。
