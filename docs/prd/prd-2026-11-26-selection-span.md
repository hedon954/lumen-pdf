# 选区就是要翻译的那段文字

对应未关闭的 GitHub issue：[#31](https://github.com/hedon954/lumen-pdf/issues/31)、[#32](https://github.com/hedon954/lumen-pdf/issues/32)、[#33](https://github.com/hedon954/lumen-pdf/issues/33)、[#34](https://github.com/hedon954/lumen-pdf/issues/34)。

## 问题

选中一整句去翻译，原文和译文变成了两句，语法树只拆了后面那句。页面滚到两句或两页交界时，选的是后面那句，语境却用了前面那句，后面那句被丢掉。从上一页底部拖到下一页，上一页里已经选中的文字不出现。翻译浮窗还开着的时候用双指滚动页面，浮窗直接消失。

## 用户行为

翻译、语法和单词释义使用的原文，就是用户选中的那段文字所碰到的句子。

- 选区停在半个词上，先补成这个词。停在半句上，补成这句的句首到句末。补全停在这句的边界上。
- 选区已经覆盖一整句时，就用这一句。前面一句、后面一句，只要选区没有碰到，就不并进来。句子恰好从选中的词开头，也仍然只是这一句。
- 选区盖住连续的几句，这几句都算进去，中间不丢句。
- 一行被排版折到下一行、行末连字符断开、或者同一句从这一页底部续到下一页，仍然是一句。另一栏、隔开的标题、以及已经结束的上一句不接进来。
- `Mr.`、小数点这种句号不把句子截断。
- 从上一页拖到下一页时，两页上选中的文字都在，阅读顺序是上一页在前。页眉页脚如果只是每页重复的，仍然不算正文。
- 页面上的临时亮黄只盖住用户实际拖过的字，不把补全出来的整句涂上去。

翻译浮窗打开之后，双指滚动、触控板缩放都只是在移动页面。浮窗留在屏幕上，并跟着选区移动。点空白处、换成另一段选区，或者主动关闭，浮窗才消失。用户已经把浮窗拖到别处时，滚动不把它拉回去，也不关掉它。

## 非目标

- 不改已保存高亮和笔记的颜色、合并与撤销。
- 不把整页正文发给模型。
- 不为某一个词或某一页写特例。

## 验收

1. 选中一整句，译文和语法分析都是这一句，不包含它前面或后面没有选到的句子。
2. 页面停在两句之间，或停在两页交界，选中后面那句，语境是后面那句。
3. 从上一页底部拖到下一页，翻译原文同时包含两页选中的文字，上一页的文字在前。
4. 翻译浮窗打开时双指滚动页面，浮窗不消失，并跟着选区移动。缩放也一样。
