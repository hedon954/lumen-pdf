# LumenPDF — Look Up 式翻译浮窗 PRD

## 1. 产品结论

单词翻译和句子翻译采用 macOS Look Up 式视觉关系：选中的单词或句子在 PDF 上保持黄色强调并带轻微阴影，实色浮窗以箭头指向该选区；同时保留用户明确需要的拖拽移动能力。浮窗内部仍是上方原文、中间译文、底部操作。翻译字段、流式生成、保存、失败重试和 AI 解释的内容与规则保持不变。

## 2. 功能需求

### F1 — 锚定浮窗、选区强调与指向

- 翻译存在期间，PDFKit 的真实当前选区继续保留；界面在对应逐行文字几何上绘制系统黄色强调和轻微阴影，形成与 macOS Look Up 相近的抬起感。关闭翻译后临时强调消失，不写入 PDF 或标注存储。
- 浮窗使用与 macOS Look Up 接近的圆角、阴影和锚定箭头，内容区域使用完全不透明的系统文本背景，不透出或模糊后方 PDF。选区左侧有空间时优先显示在左侧，靠近左缘时显示在右侧；箭头始终朝向当前选区。
- 浮窗保留拖拽移动按钮。拖动后浮窗必须限制在阅读区域内，箭头继续表达浮窗与原选区的关系；点击外部或关闭按钮即可关闭，不提供缩放手柄。
- 用户滚动或缩放 PDF 时关闭浮窗并清理临时强调，避免选区离开原位置后留下不再指向文字的悬空箭头。
- 宽度、自动内容高度、滚动和窗口高度上限沿用 `main`：单词 380pt、句子 560pt 起步，按文字长度扩展，宽度不超过 760pt；内容按实际高度展开，整体不超过阅读窗口高度的 80%。
- 笔记和选区操作栏仍用原来的薄材质阅读浮层，不受影响。

### F2 — Look Up 式排版

- 顶部直接显示原文；单词模式下音标紧跟单词并保持在同一行，不再单独换行。
- 句子模式的原文按可用宽度自然换行并撑高标题栏，必须完整显示，不使用单行截断或省略号。
- 顶部右侧依次放置拖拽、原文播放、刷新和关闭共四个按钮。四个按钮使用相同尺寸、同一水平线和相同的小间距，作为一组整体右对齐；加载期间刷新按钮可以禁用，但不得消失或导致其余按钮移位。
- 不再显示「英语 (美国)」原文语言标签。
- 一条细分割线后是译文语言标签和译文。译文与其语言标签使用系统强调色。译文右侧有圆形播放按钮。
- 译文语言标签跟随当前目标语言：简体中文显示「中文 (普通话，简体)」，繁体、英语、日语、韩语使用对应系统式名称。

### F3 — 已有翻译内容保持不变

- 单词模式仍展示语境翻译、音标、语境解释、词源 / 历史故事、通用释义、原文语境及其整句译文。语境翻译作为上方强调色译文，不再单独再用「语境翻译」小标题重复一遍。
- 句子模式仍展示原文、整句译文、解释和拆解。原文和译文进入原生预览的上下两段，解释与拆解保留在分割线下方。
- 流式生成时，已到达的字段立即可见。强调色译文一旦出现，就不再转圈；未写出译文前才显示「翻译中…」。
- 模型 JSON 已经闭合、或网关给出 `finish_reason` / `[DONE]` 后，必须结束流式等待。不得因为后续思考 token 或词典音标请求而一直转圈。
- 词典音标最多额外等待约 1.5 秒；超时保留模型给出的音标。
- 兜底译文仍标注「基础翻译」。失败、部分失败和重试规则不变。

### F4 — 操作

- 生成结束后，footer 左侧提供「拷贝译文」，只复制当前强调色译文（单词为语境翻译，句子为整句译文）。
- 「AI 解释」仍在保存动作左侧；「保存到单词本 / 保存到笔记」、已保存状态和删除保持原语义。
- 原文播放使用英语语音，译文播放使用当前目标语言语音。

## 3. 非目标

- 不接入系统 Translation 框架，也不把翻译结果换成系统译文。
- 不改变 prompt、缓存、LLM / 兜底链路或保存到单词本 / 笔记的数据。
- 不把翻译浮窗改成独立 `NSPanel` 或子窗口；浮层仍属于主阅读窗口内同一 SwiftUI 层级。
- 不增加用户缩放翻译浮窗的手柄。
- 不改变笔记浮层、选区操作栏的定位和外观。

## 4. 验收标准

1. 单词翻译浮窗上段是原文，下段是语境翻译；音标、语境解释、词源、通用释义和原文语境仍可看到且内容与改前一致。
2. 句子翻译浮窗上段是选区原文，下段是整句译文；解释和拆解仍在下方，内容与改前一致。
3. 浅色和深色外观下，译文及其语言标签使用强调色，顶部原文和音标分别使用主色与次级色；不出现「英语 (美国)」；单词和音标处于同一行。
4. 「拷贝译文」把强调色译文写入剪贴板；「AI 解释」、保存、关闭和点外关闭仍可用。
5. 加载和流式期间先显示原文；译文写出后转圈消失。内容增长时沿用 `main` 的自动高度与滚动规则，窗口不超过阅读区域高度的 80%。
6. 单词和跨行句子都按逐行选区显示黄色高亮与轻阴影；浮窗箭头指向选区。关闭浮窗后临时高亮完全清理，不生成持久标注。
7. 浮窗内容区域完全不透明，PDF 文字、图片或色块均不会透出，也不会形成干扰阅读的背景模糊影像。
8. 浮窗显示期间滚动或缩放 PDF，会同时关闭浮窗和临时高亮；不会在旧屏幕坐标留下悬空浮窗。
9. 顶部拖拽、播放、刷新、关闭四个按钮均为 28pt，位于同一水平线，以 4pt 等间距紧凑排列并整体右对齐；拖拽第一个按钮会移动浮窗且不会触发关闭。
10. 长句原文在四按钮左侧完整换行，按钮组保持右上对齐；文字不得被按钮覆盖、截断或显示省略号。
