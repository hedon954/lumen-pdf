# LumenPDF — 原生翻译预览样式 PRD

## 1. 产品结论

单词翻译和句子翻译浮窗改成 macOS 系统「翻译 / 查询」预览的视觉结构：上方原文、中间译文、底部操作。翻译字段、流式生成、保存、失败重试和 AI 解释的内容与规则保持不变，只改呈现方式。

## 2. 功能需求

### F1 — 原生预览排版

- 浮窗使用系统材质、连续圆角和轻阴影，看起来像系统翻译预览，而不是带大标题的卡片。
- 顶部是原文语言标签（英语 (美国)）和原文；原文右侧有圆形播放按钮。单词模式在原文下继续显示音标。
- 一条细分割线后是译文语言标签和译文。译文与其语言标签使用系统强调色。译文右侧有圆形播放按钮。
- 译文语言标签跟随当前目标语言：简体中文显示「中文 (普通话，简体)」，繁体、英语、日语、韩语使用对应系统式名称。
- 不增加指向选区的三角箭头；浮窗仍可拖动、缩放，并沿用既有定位与点外关闭。

### F2 — 已有翻译内容保持不变

- 单词模式仍展示语境翻译、音标、语境解释、词源 / 历史故事、通用释义、原文语境及其整句译文。语境翻译作为上方强调色译文，不再单独再用「语境翻译」小标题重复一遍。
- 句子模式仍展示原文、整句译文、解释和拆解。原文和译文进入原生预览的上下两段，解释与拆解保留在分割线下方。
- 流式生成时，已到达的字段立即可见；未完成的译文段显示「翻译中…」或「正在生成…」。
- 兜底译文仍标注「基础翻译」。失败、部分失败和重试规则不变。

### F3 — 操作

- 生成结束后，footer 左侧提供「拷贝译文」，只复制当前强调色译文（单词为语境翻译，句子为整句译文）。
- 「AI 解释」仍在保存动作左侧；「保存到单词本 / 保存到笔记」、已保存状态和删除保持原语义。
- 原文播放使用英语语音，译文播放使用当前目标语言语音。

## 3. 非目标

- 不接入系统 Translation 框架，也不把翻译结果换成系统译文。
- 不改变 prompt、缓存、LLM / 兜底链路或保存到单词本 / 笔记的数据。
- 不把翻译浮窗改成独立 `NSPanel`。

## 4. 验收标准

1. 单词翻译浮窗上段是原文，下段是语境翻译；音标、语境解释、词源、通用释义和原文语境仍可看到且内容与改前一致。
2. 句子翻译浮窗上段是选区原文，下段是整句译文；解释和拆解仍在下方，内容与改前一致。
3. 浅色和深色外观下，译文及其语言标签使用强调色，原文使用主色。
4. 「拷贝译文」把强调色译文写入剪贴板；「AI 解释」和保存仍可用。
5. 加载和流式期间先显示原文，译文段显示进度，完成后不跳到选区另一侧。
