# LumenPDF — 阅读选择控件与窗口延续性优化 PRD

**版本**: v1.0.16 · **日期**: 2026-07-13

## 1. 产品结论

v1.0.16 优化 PDF 阅读页中两类贴近原文的轻量控件：已有笔记的快捷按钮，以及选中文本后出现的操作栏；同时恢复上次退出前的主窗口与阅读布局，让重新打开应用成为阅读过程的延续，而不是一次新的布局初始化。

笔记按钮应优先进入划线四周的正文空白，而不是固定紧跟最后一个字符。选择操作栏必须完整显示在左右侧栏之上，并在 PDF 缩放后继续遵守点击其他区域关闭的交互语义。

## 2. 背景与问题

1. 笔记按钮固定跟随划线末端时，容易覆盖下一行或正文字符。
2. 选择操作栏在 PDF 阅读区内部渲染时会被 `NavigationSplitView` 的列边界裁切。
3. 为绕过裁切而引入独立窗口后，展示、坐标和外部点击分别落入不同生命周期，出现操作栏不显示、产生阴影、重复残留，以及缩放后无法通过外部点击关闭等回归。
4. 连续修补单个现象无法恢复稳定行为，需要重新统一展示所有权。
5. 主窗口只在部分 resize 路径保存 frame，启动时也没有在窗口挂载完成后显式恢复；左侧目录的显示状态和拖拽宽度没有持久化，导致重新打开后窗口大小和三栏比例回到默认值。
6. 仅恢复文档、页码和纵向滚动位置仍不足以还原阅读现场：用户手动缩放 PDF 后，PDFKit 的缩放模式、缩放比例和横向平移会回到默认值，导致相同窗口布局下正文大小与可见区域明显不同。

## 3. 产品目标

1. 笔记按钮尽量不遮挡正文，并在密集文本中采用明确的最小遮挡 fallback。
2. 选择操作栏高于左侧目录和右侧 Inspector，靠近侧栏时仍完整可见。
3. 操作栏保持透明材质、细描边和无阴影视觉。
4. 点击操作栏之外的窗口区域始终关闭操作栏，包括 PDF 缩放之后。
5. 同一窗口中只存在一个操作栏实例，后一次选区替换前一次选区。
6. 展示逻辑保持在主窗口 SwiftUI 视图树中，不引入额外面板生命周期。
7. 恢复上次主窗口的位置和尺寸，并在显示器环境变化时保证窗口仍完整可见。
8. 恢复左侧目录和右侧 Inspector 的显示状态、宽度与模式。
9. 恢复上次主功能页、文档和完整 PDF 视口，包括缩放模式、缩放比例与横纵偏移，保持阅读现场连续。

## 4. 非目标

- 不改变翻译、解释、高亮、划线和笔记动作的业务含义。
- 不修改笔记数据库、Annotation 持久化格式或 Rust/UniFFI 接口。
- 不改变翻译、笔记编辑和笔记回顾的公共窗口外壳。
- 不要求操作栏在 PDF 缩放过程中持续追踪原选区；缩放后的下一次窗口内点击应可靠关闭，新的文本选择会产生新的锚点。
- 不恢复翻译窗口、笔记编辑框、操作栏等瞬时浮层。
- 不绕过用户的 macOS 窗口恢复系统设置强制重开额外窗口。

## 5. 功能需求

### F1 — 笔记按钮空白定位

- 根据划线矩形、页面正文行矩形和当前阅读区域计算按钮位置。
- 按右侧、上方、下方、左侧的顺序评估候选位置。
- 候选位置只有在按钮完整位于阅读区域内，且不与正文行相交时才可采用。
- 多行划线使用第一行、最后一行和整体包围框产生候选位置。
- 当四周均没有完整空白时，按钮回退到最后一个字符右上方的行间空隙，并限制在阅读区域内。

### F2 — 操作栏展示层级

- 操作栏由阅读窗口根层持有和渲染，视觉层级高于左侧目录、PDF 阅读区和右侧 Inspector。
- 操作栏不得被 `NavigationSplitView` 的任一列边界裁切。
- 操作栏超出窗口边界时应整体限制到窗口可见区域内。
- 不得通过 `NSPanel`、子窗口或向 `NSHostingView` 注入临时子视图实现层级提升。

### F3 — 操作栏关闭语义

- 点击操作栏内部按钮时执行对应动作，不触发外部点击关闭分支。
- 点击 PDF、左侧目录、右侧 Inspector、工具栏或窗口内其他区域时关闭操作栏，同时保留原点击的正常效果。
- PDF 缩放、滚动或内部视图更新不得使外部点击监听失效。
- 切换文档、切换主功能页或应用失去激活状态时关闭操作栏。
- 新选区替换旧选区，窗口内不得同时显示多个操作栏。

### F4 — 视觉

- 操作栏使用透明系统材质和 Capsule 细描边。
- 操作栏不添加阴影，也不显示独立窗口的矩形底色。
- 按钮布局、图标和现有动作顺序保持不变。

### F5 — 主窗口与阅读布局恢复

- 主窗口移动、任意尺寸变化、关闭和应用退出时保存当前位置与尺寸。
- 应用重新打开时，在主窗口完成挂载后恢复保存的 frame，避免被 SwiftUI 首轮布局覆盖。
- 保存的窗口位于已断开的外接显示器时，应在当前可用显示器中选择最接近的位置，并把整个窗口限制到可见区域。
- 保存并恢复左侧目录的显示状态和用户拖拽后的实际宽度。
- 继续保存并恢复右侧 Inspector 的显示状态、实际宽度和当前模式。
- 保存并恢复上次所在的主功能页；现有最后文档、页码和滚动位置恢复机制保持生效。
- 按文档保存 PDFKit 的自动缩放模式或手动缩放比例，以及当前横向、纵向视口偏移。
- 恢复顺序必须为缩放状态、目标页、横纵偏移；PDFKit 完成内部布局后再次校准偏移，避免首轮布局覆盖已恢复视口。
- 没有完整视口记录的旧数据继续使用现有页码和纵向滚动位置作为兼容 fallback。
- UI 测试启动参数不得污染正常用户的主功能页偏好。

## 6. 验收标准

1. 段尾、段首或页边存在空白时，笔记按钮进入可用空白且不覆盖正文。
2. 划线位于密集句子中间时，笔记按钮位于末字右上方的行间空隙。
3. 靠近左侧目录或右侧 Inspector 选择文本时，操作栏完整显示在侧栏之上。
4. 操作栏透明、无阴影，窗口内始终只有一个实例。
5. 点击 PDF、目录、Inspector 或工具栏后，操作栏关闭且原点击继续生效。
6. 选择文本并缩放 PDF 后，再点击其他区域，操作栏仍立即关闭。
7. 连续选择两段文本后，按钮只作用于最新选区。
8. 调整主窗口大小和位置后退出并重开，窗口恢复到关闭前状态。
9. 调整左右栏宽度或隐藏任一侧栏后退出并重开，三栏布局保持一致。
10. 关闭前切换主功能页、Inspector 模式，并手动缩放、横向平移及纵向滚动 PDF，重开后恢复相同正文大小和可见区域。
11. 外接显示器断开后重开应用，保存的窗口会被限制到当前屏幕可见区域。
12. macOS Debug 构建通过；原生 PDFKit 与窗口恢复交互由人工验收。
