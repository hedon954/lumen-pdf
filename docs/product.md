# LumenPDF 当前产品行为

当前行为写在本文。决策按什么顺序落地，见 [history.md](history.md)。实现边界见 [architecture.md](architecture.md)。

macOS PDF 阅读器：翻译、划线、笔记、单词本、AI 导读在同一阅读窗口完成。不配置 LLM 也能用基础翻译；上下文解释和追问需要 OpenAI 兼容接口。

## 文库

工具栏「文库」弹出最近打开的 PDF：封面缩略图、文件名、进度（第 n / 总页）。从文件选择器打开；从列表移除不删除磁盘文件。跨重启用 security-scoped bookmark 访问原文件。

## 阅读窗口

三栏：目录 · PDF（连续竖向滚动）· Inspector。划选文本后，阅读窗口根层出现选区操作栏：翻译 / 高亮 / 下划线 / 笔记 / 解释。操作栏和翻译、笔记浮窗不被分栏裁切。

浮窗首次定位优先：选区下 → 上 → 右 → 左；尽量少水平挪动，实在避不开才重叠。翻译和笔记浮窗可从四向箭头拖动；点外侧或 × 关闭。翻译浮窗**第一次落下后锁定原点**，内容变高只向下长，不再换边跳位。

不把小节标题仅因正文复述了相同词而塞进翻译原文（未被高亮的标题、且词组已出现在正文中则剥离）。

## 翻译

单词/句子都走流式。从选区抽出整句，带上下文请求 LLM JSON。降级链：SQLite 缓存（仅 LLM 成功写入）→ LLM → MyMemory。期望 JSON 的输出先 json repair 再解析；流式 UI 只剥代码围栏，中途不做 repair。

每个 `/chat/completions` 合并 Extra Config 默认值以关闭 thinking；不用 `/no_think` 后缀。服务端因 thinking 字段返回 400 时，剥掉这些字段再试一次。

翻译气泡：音标、语境义、解释、整句译文、TTS、存/删单词。失败可刷新；成功也可重新生成（跳过缓存读取）。

## 笔记

绑在 PDF 选区上，SQLite 持久化，打开文档时恢复下划线。Inspector 笔记页、回顾浮窗、全局笔记列表可编辑；停顿约 450ms 或失焦后自动保存，并提示成功/失败。**新建草稿**仍须显式保存；trim 后为空禁止提交。回顾浮窗可删单条或该选区全部笔记（含对应划线）。

## 单词本

按 lemma 分组；同一词可有多条语境（来源 PDF/页、查询次数、音标、可编辑字段）。保存时加黄色高亮；删除时去掉高亮。从列表跳回原文**不**自动弹出翻译。

## 划线

自由高亮（`__fh`，黄）与下划线（`__fu`，蓝）；单词高亮用词条 UUID，与自由划线分开。同一文本行上区间重叠则合并，完全覆盖则取消；相邻行即使包围盒在竖直方向重叠，只要不是同一文本行，不得误删。支持跨页落笔；页眉页脚与标题回声有诊断，不作为普通正文划线。

## Inspector 与 AI 导读

三模式：上下文（附近单词/笔记）· 导读 · 当前文档笔记。「解释」进入导读：可展开原文卡片、失败原位重试、模型支持时附图。导读会话不持久化完整聊天记录；会话还开着时可用 ⌘F 搜到。调用日志：类型、模型、token、耗时、失败原因；可展开实际 HTTP 请求（密钥脱敏）。

## 设置 / LLM

侧栏设置。服务商菜单：内置列表之后固定「其他」。规范化 Base URL 对不上任何内置项时，菜单勾「其他」，不就近冒充内置商。选「其他」不得覆盖已填的地址、模型、Key、Extra Config；从内置切到「其他」再切回，自定义配置还在。

Base URL 与模型存 UserDefaults；API Key 存 Keychain（一项，按端点映射）；Extra Config 按 Base URL 存 UserDefaults。空 Extra Config 显示并使用 Rust `default_extra_config` 的关 thinking 默认；用户保存的 JSON 对象（含 `{}`）按原样用。`{}` = 不附加字段。编辑器：语法着色、回车按层级缩进、画笔才整段格式化。内置商显示官方 API Key 链接；「其他」不显示。

保存失败只在设置页保存栏提示可读原因，不弹主窗口 toast、不展示 Sec 错误码。ad-hoc 安装遇到 Keychain `-34018` 时改写入普通钥匙串。提示词校验同时检查 User / System Prompt 的动态变量。有用量/token 热点图。

## 窗口与视口

持久化：主窗口 frame、左右分栏显隐与宽度、当前标签/文档、PDF 视口（缩放模式、比例、水平/垂直偏移，用文本锚点恢复）。最小化再展开、退出再打开都恢复。用户一旦手动滚动，停止用旧快照「纠正」。不恢复：选区、操作栏、翻译/笔记浮窗、搜索词。

## 工作区搜索

主阅读窗口 ⌘F / 菜单「查找…」/ 工具栏放大镜：居中胶囊搜索条，盖住三栏。默认搜笔记和划线；单词、当前 PDF 原文、当前 AI 会话默认关，点开才索引。至少 2 个字符；不区分大小写；空格分词须全部命中。↑↓ 移动、Return 打开、Esc 或点外侧关闭。关闭后不记住查询。设置窗口不劫持 ⌘F。单词本和笔记页自己的搜索框仍在。

## 非目标

- 不索引未打开 PDF 的全文，也不做跨文件原文检索。
- 不把任意 URL 归到某个内置服务商。
- 不重新启用 App Sandbox（历史数据在非容器路径）。
- 不把翻译、笔记、设置做成独立系统窗口。
