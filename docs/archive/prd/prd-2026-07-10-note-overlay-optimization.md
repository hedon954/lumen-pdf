# LumenPDF — 阅读浮层与划线回顾优化 PRD

## 1. 产品结论

v1.0.15 统一阅读页中的窗口型浮层体验。翻译、添加/追加笔记、笔记回顾虽然内容与操作不同，但外围窗口遵循同一套规则：默认避让当前选区、内容高度自适应、最高占阅读区域高度的 80%、超出后仅正文滚动，并共享拖动、缩放、边界限制和关闭行为。

选择文本后出现的快捷操作条仍是贴近选区的上下文工具条，不属于窗口型浮层，不纳入本次公共窗口规则。

## 2. 背景与问题

此前各浮层独立实现外围窗口逻辑，导致行为逐渐分叉：

1. 笔记浮层会避让选区，但翻译浮层仍可能固定居中并遮挡原文。
2. 长内容虽局部加入滚动，但外层高度规则不统一，可能过高、截断或留下大块空白。
3. 拖动、缩放、窗口边界和重置逻辑分散在多个 View 中，修复一个浮层不会自动覆盖其他浮层。
4. 已有笔记缺少从 PDF 原文快速回顾的入口。
5. 笔记回顾浮层中的“打开右侧笔记”此前没有真正切换并打开 Inspector。

## 3. 产品目标

1. 所有窗口型阅读浮层默认不遮挡当前选区。
2. 浮层高度随内容自适应，而不是固定为某个比例。
3. 浮层最大高度为当前阅读区域高度的 80%；达到上限后保持该高度，正文内部滚动。
4. 当浮层达到最大高度时，上下各保留阅读区域高度的 10%。
5. 标题栏、正文、底部操作区职责稳定：标题栏拖动，正文滚动，底部操作固定。
6. 从 PDF 原文旁的笔记图标可打开回顾浮层，并能进一步打开右侧笔记 Inspector。
7. 外围窗口逻辑只有一个事实来源，后续新增阅读浮层直接复用。

## 4. 非目标

- 不改变笔记数据库结构、Markdown 格式或导出格式。
- 不改变翻译结果、保存单词、发音和翻译 fallback 行为。
- 不重做 Reading Inspector 或完整 PDF 批注侧栏。
- 不把系统 popover、右侧 Inspector、选择快捷操作条强行改成窗口型浮层。
- 不在本版本增加笔记标签、筛选、搜索、重命名或复杂编辑能力。

## 5. 功能需求

### F1 — 公共窗口外壳

以下浮层必须复用同一个外围窗口组件：

- 翻译浮层。
- 添加/追加笔记浮层。
- 笔记回顾浮层。

公共外壳统一负责：

- 标题栏、正文、底部操作区的结构。
- 毛玻璃、圆角、描边、阴影等窗口样式。
- 默认定位、选区避让和可见区域 clamp。
- 标题栏拖动。
- 可选的边缘/角落缩放。
- 内容测量、自适应高度和内部滚动。
- 点击背景关闭、状态重置和窗口尺寸变化处理。
- 浮层层级和互斥关系；同一时间只显示一个窗口型阅读浮层。

各业务浮层只提供自己的 header、content、footer 和少量配置，不得再次实现一套拖动、滚动或定位状态。

### F2 — 内容自适应与最大高度

- 浮层实际高度应跟随标题、正文和底部操作的内容高度变化。
- 短内容保持紧凑，不得为了满足比例而固定占用阅读区域的 80%。
- 总高度计算遵循：`min(内容所需高度, 当前阅读区域高度 × 80%)`。
- 当内容超过最大高度时，外层窗口保持在最大高度，只有正文区域上下滚动。
- 标题栏和底部主操作按钮始终可见，不随正文滚走。
- 手动缩放同样不得超过 80% 的垂直上限。
- 流式翻译内容增长时，浮层可以逐步增高；到达上限后不再增长，转为内部滚动。
- 浮层打开时只确定一次默认避让方向；流式内容增长不得让窗口从上方跳到左侧等其他方向。
- 外部阅读区域缩放后，应重新限制浮层尺寸和位置，不得把标题或操作区推出可见范围。

### F3 — 默认避让选区

- 翻译、添加笔记和笔记回顾打开时，应使用当前选区或笔记锚点的阅读区域坐标定位。
- 默认位置优先级为：下方、上方、右侧、左侧。
- 每个候选位置都必须先限制在可见区域，再计算与锚点的重叠面积。
- 优先选择不重叠的位置；全部重叠时选择遮挡面积最小的位置。
- 浮层最大高度时，其垂直位置固定在上下各 10% 的安全区域内。
- 多行选区使用整体 bounding rect 作为避让对象。

### F4 — 拖动与缩放

- 窗口标题栏支持拖动，正文、按钮和输入框不触发窗口拖动。
- 拖动后浮层仍被限制在阅读区域可见范围内。
- 新的浮层会话重新按新锚点定位，不沿用上一次手动位置。
- 翻译浮层继续支持边缘和角落缩放，并显示对应鼠标指针。
- 缩放后正文滚动、保存、发音和关闭行为必须保持可用。
- 添加笔记和笔记回顾暂不开放手动缩放，但仍复用相同的高度与滚动规则。

### F5 — 已有笔记图标与回顾

- 已有笔记划线在原文附近显示轻量 `note.text` 图标。
- 多行划线优先把图标放在最后一行末端，不覆盖正文主体。
- 同一选区的多条笔记合并为一个入口，并在回顾浮层中按创建时间展示。
- 回顾浮层展示原文、笔记内容、创建时间、关闭操作和“打开右侧笔记”。
- 保存、追加或删除笔记后，图标状态及时刷新。
- PDF 连续滚动、惯性滚动或缩放后重新回到笔记位置时，图标必须重新出现并跟随原文坐标。

### F6 — 打开右侧笔记

点击“打开右侧笔记”后必须：

1. 刷新当前笔记数据。
2. 将 Reading Inspector 切换到“笔记”模式。
3. Inspector 隐藏时将其打开。
4. 关闭当前笔记回顾浮层。

本版本不要求自动滚动到右侧的具体笔记卡片。

### F7 — 划线与笔记的空值边界

- “划线”是独立批注动作，不要求笔记内容，也不创建空笔记记录。
- “笔记”和“追加笔记”必须包含 trim 后的非空内容。
- 输入为空或仅包含空白字符时，“保存”按钮禁用，默认回车操作也不得提交。
- 空内容不得写入笔记存储，也不得以“空笔记等于划线”的方式创建关联划线。
- 取消已有笔记使用独立删除路径，不再通过空笔记内容触发删除。

### F8 — 右侧单词与笔记删除

- Reading Inspector 的单词卡和笔记卡都提供卡片级删除按钮。
- 删除单词时，同时删除词条数据和 PDF 原文中的关联高亮。
- 删除笔记时，同时删除该卡片代表的笔记数据、关联划线和原文快捷图标。
- 同一选区聚合了多条笔记时，删除卡片表示删除该组选区下的全部笔记。
- 删除完成后刷新当前 Inspector 列表；最后一项删除后显示对应空状态。

## 6. 交互与视觉规则

- 浮层继续使用轻量毛玻璃、圆角、细描边和克制阴影。
- 横向保留最小窗口安全间距；纵向使用阅读区域高度的 10% 作为安全边界。
- 正文滚动优先消费触控板、滚轮和滚动条输入，不应误带动 PDF 页面。
- `TextEditor` 保留自身输入与滚动能力，不因窗口拖动而失焦。
- 选择快捷操作条继续贴近选区显示，它是上下文操作，不采用公共窗口外壳。

## 7. 验收标准

1. 翻译、添加/追加笔记、笔记回顾均复用同一个外围窗口组件。
2. 三类浮层打开时默认尽量不遮挡选区或对应笔记原文。
3. 短内容浮层随内容收缩，不固定为 80% 高度。
4. 长内容浮层最大为阅读区域高度的 80%，上下各保留 10%，正文可滚动到底部。
5. 流式翻译增长到上限后外层高度保持稳定，标题栏和底部操作区仍可见。
6. 标题栏拖动后浮层不会跑出可见区域；翻译浮层缩放不超过 80% 高度。
7. 点击已有笔记图标可打开回顾浮层；点击“打开右侧笔记”会显示 Inspector 并切换到笔记模式。
8. 保存、追加和删除笔记后，原文图标与右侧笔记数据正确刷新。
9. macOS Debug 构建通过；原生 PDFKit 交互由人工验收。
10. 应用版本号更新为 `1.0.15`，内部构建号更新为 `15`。
11. 翻译加载态到完成态期间，浮层保持首次选定的避让方向，不因内容高度变化发生横向跳位。
12. 新建或追加笔记时，trim 后为空则保存按钮不可用，且不会创建或更新笔记记录。
13. 将笔记划线滚出视口后再滚回，快捷笔记图标会在原位置重新出现。
14. 右侧单词卡和笔记卡均可删除；数据、PDF 高亮或划线以及快捷图标同步更新。
