# LumenPDF — 阅读上下文与 AI 导读 PRD

## 1. 产品结论

LumenPDF 的阅读页需要同时承担阅读、理解、标注和复习。当前版本在 PDF 右侧提供当前文档的单词和笔记上下文；在选区解释中提供可追问、可保存、可缩放的 AI 导读窗口；在笔记系统中支持同一选区的多条笔记分开展示。

## 2. 目标

1. 阅读 PDF 时直接看到当前文档的单词和笔记，不离开阅读页。
2. 单词、笔记、AI 回复都能回到原文选区，保留页码和位置感。
3. 划线用于快速标记，笔记用于沉淀想法，两者入口和保存语义分开。
4. AI 导读支持围绕同一选区连续追问，并能把每条 AI 回复保存为笔记。
5. 本地安装或重装后，已保存的 API Key 不应反复触发钥匙串授权弹窗。

## 3. 非目标

- 不移除顶部「单词本」「笔记」管理页。
- 不新增云同步、多用户协作或聊天记录持久化。
- 不新增 Rust 数据结构和数据库迁移。
- 不实现 PDF 标注点击后反向选中右栏卡片。
- 不把右栏做成可拖拽调整宽度的独立 split view。

## 4. 功能需求

### F1 — 阅读上下文右栏

- 右栏只在 PDF 阅读页且已打开 PDF 时显示。
- 右栏展示当前 PDF 的数据：
  - 单词：`VocabularyEntry.pdfPath == selectedDocument.filePath`
  - 笔记：`NoteEntry.pdfPath == selectedDocument.filePath`
- 右栏提供「单词 / 笔记」两个分段入口，不提供混合列表。
- 列表按页码升序展示，同页内按创建时间降序和稳定 ID 排序。
- 右栏默认开启，工具栏按钮可显示 / 隐藏；显隐切换后尽量保持 PDF 页码和页内滚动位置。

### F2 — 阅读位置联动

- PDF 当前页变化时，右栏自动滚动到当前页或之后最近的条目。
- 用户手动滚动右栏到其他页码分组时，PDF 同步跳转到该页。
- 点击单词或笔记卡片时，PDF 跳转到对应页，并尽量滚动到选区附近。
- 成功定位后短暂展示选区焦点，并用 Toast 告知目标页码。

### F3 — 单词卡片

- 展示单词、语境翻译、原文语境、页码和「单词」标识。
- 卡片内容保持短预览，点击卡片回到 PDF 原文选区。

### F4 — 笔记卡片

- 笔记按同一 PDF、同一页、同一选区 bounds、同一原文内容分组。
- 同一选区下的多条笔记分开展示，每条笔记显示创建时间。
- 笔记内容支持 Markdown 渲染。
- 笔记卡片默认收起，显示可读预览；展开后展示完整内容，不做硬截断。
- 卡片头部显示原文、页码、「笔记」标识和同组笔记数量。

### F5 — 划线与笔记

- 选区菜单同时提供「划线」和「笔记」。
- 「划线」只写入普通 PDF 下划线，不弹出输入框，不创建笔记。
- 「笔记」展示轻量输入框，可填写理解、疑问或总结。
- 笔记内容可留空；留空时只保存笔记划线和原文。
- 完整选中已有笔记划线时，提供「添加笔记」和「取消笔记」：
  - 「添加笔记」向现有选区追加新的笔记内容。
  - 「取消笔记」删除该笔记及其关联下划线。

### F6 — 笔记合并语义

- 完全相同选区：通过「添加笔记」追加内容；通过「取消笔记」删除。
- 新选区完全位于已有笔记内部：不创建重复笔记。
- 新选区与已有笔记部分重叠且包含新增区域：合并为扩展后的选区。后续修订：部分重叠只计同一文本行上的水平区间，相邻行框的垂直重叠不算，见 [prd-2026-08-21-markup-interval-merge.md](prd-2026-08-21-markup-interval-merge.md)。
- 无重叠：创建新的独立笔记。
- 合并只在同一文本行上合并相交或相邻矩形，跨行选区保留逐行 bounds。

### F7 — AI 导读多轮追问

- 点击「解释」后先展示问题输入框和原文，不立即请求 LLM。
- 输入问题后提交；留空提交时生成通用解释。
- AI 回复以聊天消息形式展示，后续追问在同一窗口继续追加。
- 后续请求携带原始选中文案、原始上下文、最近 10 轮问答和压缩后的更早上下文。
- 关闭解释窗口后，本次临时对话结束。

### F8 — AI 导读窗口交互

- 窗口可拖动和缩放。
- 鼠标移动到可缩放边缘或右下角时显示 resize cursor。
- 输入框在进入解释界面和 AI 回复完成后自动获得焦点。
- 流式输出只有在用户停留在消息底部时才持续跟随到底部；用户向上阅读时不强制滚动。
- AI 消息、笔记预览和右栏笔记均支持 Markdown 渲染。
- 样式保持 macOS 原生、低干扰、高对比的阅读窗口质感。

### F9 — 保存 AI 回复到笔记

- 每条已完成的 AI 回复都可以单独保存为笔记。
- 底部按钮在没有任何 AI 回复被保存时显示「保存所有AI回复」。
- 保存任意一条 AI 回复后，底部状态显示「已保存到笔记」和删除按钮。
- 删除按钮删除本次窗口中所有已保存的 AI 回复笔记，并刷新右栏 / 笔记页。
- 保存后的 AI 回复作为同一选区下的独立笔记展示，带创建时间。

### F10 — 数据刷新

右栏和管理页应响应以下变化：

- 打开或切换 PDF；
- 保存或删除单词；
- 新增、编辑或删除笔记；
- 保存或删除 AI 回复笔记；
- 当前页变化。

### F11 — API Key 持久化

- API Key 仍存入 macOS Keychain。
- 本地重新安装或升级 App 后，读取已有 API Key 不应反复弹出登录钥匙串授权。
- 旧钥匙串条目可迁移到稳定服务名下继续读取。

## 5. 验收标准

- 阅读页能在右栏查看当前 PDF 的单词和笔记。
- 右栏跟随 PDF 当前页，手动滚动右栏也能同步 PDF 页码。
- 点击右栏卡片能跳转并聚焦原文选区。
- 普通划线不弹笔记输入框；笔记入口可以追加多条内容。
- 同一选区的多条笔记分开展示，带时间，支持展开和 Markdown。
- AI 导读可连续追问，流式输出不打断用户向上阅读。
- AI 回复可逐条或全部保存为笔记，删除按钮能删除已保存回复。
- 重装后读取 API Key 不再要求用户重复输入钥匙串密码。
